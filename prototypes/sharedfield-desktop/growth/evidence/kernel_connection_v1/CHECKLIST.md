# 内核连接恢复：事前清单

2026-10-03，基线 a5504f6d。负责人反馈“连不上”。旧会话因 30 分钟期限正常关闭；重启后 MC 已入服，但 AIRI 多窗口仍使用旧令牌。原生 Refresh 后 HTTP 回显收到完成事件，Chat 列表没有显示对应回复，不能据此声称桌面显示已修复。

1. 仅 error、没有 close 时，等待既有 5 秒间隔后重新连接；error/close 重复通知不能生成多个重连计时器，过期 socket 不能改变新连接状态。
2. 退出后取消重连；离线待回显队列沿用最多 20 条，不触发模型或 MC 动作。
3. 离线 Node 回归覆盖上述状态变化及已有单一 AIRI 目标路由。
4. 新正式会话确认 MC 入服、生成代码关闭；AIRI 使用新本机令牌。原生缓存回显必须收到 HTTP 回放和 AIRI 完成事件，并在 Chat 窗口看到对应回复，才算显示通过。若没显示，记录局限，不改结果标准。
5. 正常关闭/重开 AIRI 后，消息桥自动恢复；MC 身体仍在线，模型调用数不因回显增加。原始记录留在 runs/，不提交。
