# P10 观察台最小原型 — 2026-10-02，按 v0.3 收窄

运行 `.venv/Scripts/python.exe scripts/observe.py`，打开 http://127.0.0.1:8766/。默认明确标为固定 noop 工程诊断；可用 --model 接已有 LM Studio 标识。--formal 则服务端拒绝所有 POST 控制。无后台云端循环。

模拟器在独立 spawn 进程持有 Host；HTTP 进程仅持有 Mailbox 副本，不能调用 Env/render。Host 在 reset/step 返回时复制帧，模拟器复制这张帧再编码。状态队列 maxsize=1，最多每秒 5 次发布，队满丢旧帧而不等待网页；允许控制另走长度 16 的白名单队列。页面信息不回流模型请求。

自由模式接管：epoch 作废在途响应、清空重复动作、发出 P9 取消事件；交还后重新 observe。云端请求可以仍在网络侧完成/计费，但旧响应不执行。模型/策略拿到的是允许观察，网页展示字段及 owner canary 不进入策略。

HTTP 只绑定 127.0.0.1；检查对端、Host、Origin、Sec-Fetch-Site；每次启动随机会话令牌，API 要求令牌，自由控制额外要求同源 Origin。正式模式 POST 服务端直接 403，按钮隐藏只是界面表现。令牌不落盘、不进日志；本机恶意程序隔离未验证。

`p10_v03.json`：**17/17 检查，2.783 秒**，覆盖：
