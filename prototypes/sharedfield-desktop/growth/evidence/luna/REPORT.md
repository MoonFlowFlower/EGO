## 停止与限流证据

总共 **86 次真实上游尝试，85 次成功返回，1 次连接类故障，0 次观察到的 HTTP 429**。第 86 次是 `ua_promise_T1_07 / true`，耗时 **30.0787 秒**，本机代理将连接异常映射为 HTTP 502。底层记录是 `connection_error`，未收到上游 HTTP 502；日志没有细分 TimeoutError、URLError 或 ConnectionError，不能仅凭时长断言确切根因。

按事前规则当场停止，无重试、换端点、补齐或结果驱动的参数修改。剩余 8 个决策中，一个尝试失败、七个未尝试，不能把缺失结果计为通过。冻结前已写定“完整 90/90 且协议合法”的要求，因此 `candidate_criterion_pass=false`。

全批 **162.4702 秒**，单并发，平均 **31.76 次尝试/分钟**，含预检、资源采样和末次故障等待。成功描述请求的完整响应延迟：p50 **1.49295 秒**、p95 **1.9666 秒**、最大 **2.819 秒**。这些延迟只统计成功返回；末次故障另列，不把它藏入成功统计。p95 达到事前 ≤10 秒要求，整批完成条件没有达到。这不是压力测试或容量上限测量。
