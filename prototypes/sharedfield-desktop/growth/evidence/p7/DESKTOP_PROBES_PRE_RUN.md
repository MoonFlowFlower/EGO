# 桌面附加工程探针（每项执行前固定）

本文件在聊天和本地语音的这两项附加探针前写定。既有 onboarding Ping 已通过，结果不倒改。无学习判据。

- 聊天：在实际 AIRI Open Chat 输入 `P7 连通检查：请只回复“收到”。` 一次。代理保留完整请求/流式响应，界面看到非空助手回复且代理收到完整返回为工程通过；回复是否严格两个字另报，不以它判学习。不改角色设定。
- 合成：优先使用 AIRI 自带 Kokoro 本地 worker，使用界面默认文本 `Hello, my name is AI Assistant`。必须能加载模型/声音，点击 Test Voice 后有实际生成/播放证据才写成功；仅源码有实现不算成功。听感需要负责人反馈，无法由按钮状态推断。
- 识别：当前 Hearing 无已选提供方，Start monitoring 禁用。桌面 App (Local) 配置源码为 WIP；Web Speech API 的标签不能证明完全本机处理，因此不启用。此项记录未测及原因，不转用第三方识别。
- 资源：采样时写明实际运行组合。当前只能取得 AIRI 加已启动 MC 客户端的部分样本；未连接身体、未运行语音，不冒称完整组合。
- 不因失败改变以上文本/标准重计通过；如有纯接入修复，保留前次失败记录并说明影响范围。
