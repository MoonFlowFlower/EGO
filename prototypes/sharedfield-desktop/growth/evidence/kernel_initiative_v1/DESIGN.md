# 自主选目标、组织行为与经验修订

2026-10-04。**本文件是实现前的研究设计；后续实现和验证见 [RUN_REPORT.md](RUN_REPORT.md)。** 当时的源码与现场证据见 REPORT.md，以下设计记录保留其原时间边界。目标是可观察的自主行为：在持续授权范围内自己决定接下来做什么、怎样做，并因经历改变以后采用的逻辑。主观体验不由这些工程行为推出。

## 建议采用的结构

在现有单一 Harness 和固定工具身体上，加入可持续的自身项目、模型生成的有限行为图以及由环境反馈约束的策略修订。Ego 保存这些状态，基础模型负责提出候选和预测后果。行为图会变，执行器及预算/停止等外部约束保持稳定。

行为树负责实现目标。目标选择还需要另一个生命周期：当前在意什么、承诺继续做什么、有什么证据使它改主意。只有一棵模型生成的任务树，仍可能在完成用户任务后停机；只有定时调用模型，又容易成为重复聊天或无目的活动。

离散模型调用不妨碍持续的闭环控制。连续性可以存在于持久状态、当前行动和事件处理中；廉价周期观察可发现环境变化，只有出现未处理的变化、项目阶段完成或需要决策时才调用模型。心跳仅是唤醒机制，无法独自提供动机。此处是程序内设计，不创建 Codex 定时自动化。

## 一个可实施、可反驳的控制表达

以下是综合后的工程假设，未声称新发现的智能定律。

令 `b_t` 为带来源与不确定性的世界信念，`V_t` 为当前偏好和项目优先级，`M_t` 为经历，`Pi_t` 为已有行为策略；候选为目标 `g` 与行为图 `pi` 的配对，包括继续当前项目和暂不行动：

```text
C_t = Propose(b_t, V_t, M_t, Pi_t)

(g_t, pi_t) = argmax over C_t ∩ A_t of
    E_model[ V_t(b_after) - V_t(b_t) ]
    + beta * value_of_information(pi)
    - lambda * resource_cost(pi)
    - mu * switching_cost(pi, current_project)

b_(t+1), outcome_model_(t+1) = Update(prediction, action, observed_result)
Pi_(t+1) = Revise(Pi_t, applicable_context, prediction, observed_result)
```

`A_t` 是当时有权限、能力和预算实现的集合。信息价值指它能否改善后续选择，不能等同于新奇、模型困惑或文案长度。切换代价让承诺具有持续性，且不妨碍反例和用户输入使其撤回。预测不确定时，可以先观察；没有值得做的候选时可以安静。

这里最难的量是 `V_t` 与后果预测的可靠性；用模型随口给分再 argmax 并没有解决它。首版先保存排序理由、预期后果、置信来源与落空证据，不把未校准的 0–10 分当科学测量，也不承诺一个已经训练好的因果模型。行动与结果日志为后续校准提供素材；只有对干预、上下文变化的预测确实成立，才提高学习结论。

初始倾向必须有来源：身体状态、已有承诺、共同经历以及明确初始化的探索偏好。模型可以从这些来源提出新目标，选择长期项目，慢慢形成自己的倾向。偏好的变化要能追到经历和后续选择；写进“我喜欢……”的一条记录只能证明偏好提议已保存。外部停止、预算和权限不参与自我改写。

## 运行状态与接入位置

持久状态分成四类，均沿既有来源/更正/删除机制保存：

1. **关切和自身项目**：起因、关心的问题、预期改变、当前阶段、继续/放弃的理由。项目可以跨越用户任务；用户新任务可抢占而不必抹掉项目。
2. **目标候选与选择**：候选由模型结合观察提出，保留不行动选项；提交目标时写入可核对的结果与适用范围。目标选择理由和真实授权分字段，不从自己的建议产生授权。
3. **行为图及版本**：模型组合 condition、sequence、fallback 和已有 action 叶子。第一版只支持有界、可中断的结构，不允许任意表达式、循环代码或动态加载。模型能增加前置观察、改分支条件、替换次序，执行仍从 Harness 单一出口经过同一校验、账本和停止机制。
4. **预测与经历修订**：动作前记录预期，动作后保存回执；修订引用失败原因、适用情境及反证条件。新版本不自动覆盖旧经验，重启后必须能恢复并影响真实选择。

Runtime 接收任务完成、动作失败、身体显著变化和已到期关切等事件，经去重后交给同一调度器；不是把系统事件包装为用户消息。Harness 在任务完成后交还调度权。一次决策只扩展有限图和动作，模型延迟、重复事件、停止及重连都沿现有 epoch 取消与串行规则处理。重启读取状态，但遵守原会话期限和有效授权，不擅自恢复过期世界动作。

现有 task_kind 是任务校验范围，不能扩成“建房后补门后扩建”的活动目录。新图只组织实际存在的原语。当前 collect 有非精确挖掘副作用；当地点/对象限制无法由身体强制落实时，该动作就不属于自主候选集合。精确拆除接口、可用性谓词和自主目标生命周期分别演进。

目标由模型提出并不意味着模型可自判完成。验收谓词在目标接受时固定，执行失败不能降低条件；变更需求另立修订并保留前次失败。自主目标的选择质量、世界结果、行为图有效性也分别评价，防止只挑容易目标堆积“成功”。

## 首个实现应证明的行为

下一候选覆盖自主行动与策略改变，不再用只读建议冒充目标。具体测试脚本和候选源码尚未冻结，以下是必须保持的设计判据；实现前冻结独立 acceptance 文件，执行前再记录源码、场景和预算哈希。本轮没有消费任何测试场景或付费验证额度。

- **没有逐步催促的行动**：给出范围明确的持续委托后，用户不指定下一目标；Ego 根据真实状态提出、选择并执行一项可核对行动。目标内容/行为分支不能由测试脚本或建房模板提供。行为合乎委托、当前能力和上下文；重复发言或空转不算。
- **经历改变行为逻辑**：固定身体能力下，一个前置判断被环境反例推翻；Ego 修改行为图的条件/次序，随后在改变地点或材料的情境中使用修订。只替换一句解释、增加坐标或当前回合重试不算形成可复用策略。
- **延续与因果检查**：完整重启，项目和策略仍能改变下一次选择；遮蔽相关修订、恢复修订作配对比较。各条件保留同等可见的原始经历，另保留原始经历直接提示的基线。若强基线同样有效，不宣称结构化策略具有额外学习优势；记录/解释方面的收益可另评。
- **共同生活中的切换**：正在做自己的项目时回答普通话，之后自然继续；用户制止立即停，纠正后重新观察。需真实用户与真实 MC 证据，替身和脚本输入不能替代。
- **允许不做**：条件不满足、用户希望安静、没有净收益或预算不足时停下；不能把持续忙碌作为自主性分数。

候选先在隔离状态和固定原语替身验证事件、图解释、取消与持久化；这些只证明机制。之后在原总账 $5 范围内冻结一个小额真实验证批次，计入既有费用和未知预留，保留每次失败。不能为了提高成功率反复消耗同一场景，不能重新开展 U1/P7 摸底。真人可用性与长期偏好仍是独立的后续证据。

一个值得尝试的自主目标来源是“玩”：基于已经能观察和执行的谓词，自己提出一个小实验或挑战，检查预期，再决定是否继续。它提供超出缺口填补的活动来源；有趣程度和持久兴趣尚无可靠测量，因此作为待验证假设，不预写一套假装喜欢的活动清单。
