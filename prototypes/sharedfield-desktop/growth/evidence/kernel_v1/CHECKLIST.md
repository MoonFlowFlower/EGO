# 共享内核 v1：接通前清单

授权：负责人 2026-10-03 要求先闭环、接通整个内核，由同一个模型处理 AIRI 与 MC。此为 P7 摸底之后的新工程批次；不修改 U1、P7 的历史提示、脚本、阈值或成绩。范围限 growth/，第三方安装在仓库外。

结构：Ego 本机内核是唯一决策与持久状态入口。AIRI 只提供输入/显示；MC 身体只执行审核过的现成函数并报告状态，不初始化 Mindcraft Agent、Prompter、独立模型、摘要或自提示循环。复用现有 ZDR 路由、共享 $5 账本、U1 可复用存储/来源校验接口；旧 U1_NOT_PASSED 不改为通过。

## 事前工程判据

1. 两个渠道进入同一 conversation_id，唯一串行决策入口使用同一固定模型路线；UI 自带历史/角色不能建立第二份权威状态。MC 进程不持有模型密钥或模型客户端。一个输入 ID 至多决策一次，向 AIRI 回显已有结果不能重复收费/执行。
2. 真实 AIRI 桌面输入与回复可见；真实 MC 的聊天输入进入内核，桌面与游戏得到同一回合的回复。通过标准 OpenAI 接口与官方 AIRI input:text 事件接线，不修改 AIRI 源码。
3. 在 AIRI 教一条显式测试约定，保存到带原话来源的约定库；完全结束内核进程，重新启动并读取同一存档；从 MC 输入该约定，模型经标注选择现成动作。教学、重启后输入和结果必须有独立回合 ID。测试内容只写本机 runs，不混入用户正式存档。
4. 动作选接近 Moonlight，限 60 秒：实际距离 <= 3.25 格且高度差 <= 1.25 格才计达到；目标不可见或没有发生可观测执行，记未证明。动作结果回流同一内核，AIRI 显示结果。不得拿模型自述代替状态。
5. 停止能中断正在执行的动作；每回合最多 8 次模型决定、最多 180 秒，重复失败动作不自动重试。到限明确报告暂停并保留待办。重启不自动重放旧动作。旧请求的迟到响应不得在取消后启动动作。
6. 持久的显式约定可更正、删除；引用必须来自该用户的实际输入。复用 U1 的引用验证；时间条件由原话的明确星期/时间确定，模型不另写数字星期。删除测试同时查 canonical 存储及依赖记录，不只删显示卡片。
7. 所有动作经过固定函数表和参数验证；禁止生成代码、shell、任意路径/URL和第三方工具。库存把可用栏、合成格、光标分开；有合成残留时拒绝继续合成，回报明确故障。
8. 独立本机主管持有运行期限和生命周期日志，退出记录原因并清理身体。云密钥仅内存；本机令牌仅 AIRI 配置允许落盘。进程参数、日志及提交不得有密钥。内容留 runs。
