# 修订 3：睡眠提炼技能

睡眠输入新增 successful_sequences：从本回合已供给的允许经历中，选最多 4 段、每段最多 8 个连续基础动作，以实际背包或 food/drink 增加收尾，带来源编号和从增益计算的完成条件候选。经历材料预留 20000 字节、经历加序列合计不超过 24000 字节；A、B 输入选择一致。两组记忆上限仍为 3000 UTF-8 字节。B 的提示词要求实际程序源码和条件表达式；即时 write 能力保留。

[工程 JSON](engineering.json)用实际轨迹产生增益序列，经替身模拟一次结构化睡眠回复，保存 goto + do 技能，并在另一固定场景的真实沙箱执行，完成条件从假变真。规则提案 schema 没有 scope。该验收证明材料/保存/调用连通；替身不证明真实模型能提炼技能。真实云调用将在 G0b/G0c 和新预实验分别记录，不改成能力声明。
