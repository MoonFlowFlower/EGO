# 观察契约 v1.1（P1，阶段 0）

自定义结构化 Crafter 任务；不能与原版 RGB 基准直接比较。

## 信任边界与允许字段

可信游戏驱动 `Host` 是传感器与执行动作的边界。只有它可访问环境；仅在采样玩家附近格子、读取 HUD、计算位移差时使用内部状态。它不构造/传出全图语义地图。策略、观察消费适配器、技能解释器只能得到经过白名单重建的 JSON。Python Host 对象从不交给生成的程序。

允许：`schema` 固定值；`tick` 已执行底层步数；`world` 随机不透明身份（不含 seed/规则）；`needs` 的 health/food/drink/energy（0–9）；12 种背包物品计数；`light` 四位小数；`radius`；局部 `cells`（dx、dy、material、entity、visible_state）；`displacement` 上一底层步真实位移差；`facing` 朝向；`sleeping`；`done`；固定全部 17 个动作的公开名称。基础动作不按当前可行性筛选。

位置选 A：真实位移差传感器。继承该额外能力，阻挡时差为 [0,0]，不暴露绝对坐标；累计路径是她可自行维护的相对地图。朝向属于可见姿态，单独登记。

夜晚规则是人工设定的可见性，不声称和像素可辨性相同：light ≥ 0.5 时 dx ±4 / dy ±3，共 63 格；0.2 ≤ light < 0.5 时 ±2，共 25 格；更暗时 ±1，共 9 格。边界外返回 unknown，不告诉地图尺寸。不实现遮挡；原版画面也显示局部全部格子。实体给可见种类；visible_state 默认 null，仅允许植物成熟布尔 plant_ripe 与箭方向 arrow_direction（up/down/left/right），按原版纹理给出且仍受范围裁剪。不给 HP、成长计数、目标或隐藏状态。

禁止：全图、绝对坐标、环境对象、RNG、seed、规则参数、奖励、成就名称/分数、配方/前置条件、可行动作筛选、oracle 失败解释、隐藏地图和评估器反馈。失败只报输入不合法/已结束等边界错误，动作结果通过允许的前后观察看到。

# 阶段 1 新增继承登记

- 变化感知：仅从允许的前后观察算出背包、真实位移、同一面前格的可见变化、进入睡眠、food/drink 增加。其余需求差值单列。`no_visible_effect`、`blocked`、`health_lost` 不解释原因，前者不等于失败。
- 受伤反射：每个基础步后检查 health 差值；技能（含子技能）、基础动作重复与直线宏一旦掉血即停，交回思考层。不能检测同一步里被恢复掩盖的净零伤害。
- 规则卡格式：动作、背包下限/3×3 材质/面前材质或实体前提、预期变化、作用域、经历来源、程序计数。格式继承，内容不预置。
- 技能语言 v2：封闭 AST，`run`、`and/or/not`，深度 3，禁止递归，最外层共享预算，完成条件由允许观察判定；无变量/算术/文件/网络。A 与 B 共用。实现验收见阶段 1 各组件报告。
