# 观察契约 v1.1（P1，阶段 0）

自定义结构化 Crafter 任务；不能与原版 RGB 基准直接比较。

## 信任边界与允许字段

可信游戏驱动 `Host` 是传感器与执行动作的边界。只有它可访问环境；仅在采样玩家附近格子、读取 HUD、计算位移差时使用内部状态。它不构造/传出全图语义地图。策略、观察消费适配器、技能解释器只能得到经过白名单重建的 JSON。Python Host 对象从不交给生成的程序。

允许：`schema` 固定值；`tick` 已执行底层步数；`world` 随机不透明身份（不含 seed/规则）；`needs` 的 health/food/drink/energy（0–9）；12 种背包物品计数；`light` 四位小数；`radius`；局部 `cells`（dx、dy、material、entity、visible_state）；`displacement` 上一底层步真实位移差；`facing` 朝向；`sleeping`；`done`；固定全部 17 个动作的公开名称。基础动作不按当前可行性筛选。

位置选 A：真实位移差传感器。继承该额外能力，阻挡时差为 [0,0]，不暴露绝对坐标；累计路径是她可自行维护的相对地图。朝向属于可见姿态，单独登记。

夜晚规则是人工设定的可见性，不声称和像素可辨性相同：light ≥ 0.5 时 dx ±4 / dy ±3，共 63 格；0.2 ≤ light < 0.5 时 ±2，共 25 格；更暗时 ±1，共 9 格。边界外返回 unknown，不告诉地图尺寸。不实现遮挡；原版画面也显示局部全部格子。实体给可见种类；visible_state 默认 null，仅允许植物成熟布尔 plant_ripe 与箭方向 arrow_direction（up/down/left/right），按原版纹理给出且仍受范围裁剪。不给 HP、成长计数、目标或隐藏状态。

禁止：全图、绝对坐标、环境对象、RNG、seed、规则参数、奖励、成就名称/分数、配方/前置条件、可行动作筛选、oracle 失败解释、隐藏地图和评估器反馈。失败只报输入不合法/已结束等边界错误，动作结果通过允许的前后观察看到。

# 阶段 1 新增继承登记

- 变化感知：仅从允许的前后观察算出背包、真实位移、同一面前格的可见变化、进入睡眠、food/drink 增加。其余需求差值单列。`no_visible_effect`、`blocked`、`health_lost` 不解释原因，前者不等于失败。
- 受伤反射：每个基础步后检查 health 差值；技能（含子技能）、基础动作重复与直线宏一旦掉血即停，交回思考层。不能检测同一步里被恢复掩盖的净零伤害。
- 规则卡格式：动作、背包下限/3×3 材质/面前材质或实体前提、预期变化、作用域、经历来源、程序计数。格式继承，内容不预置。
- 技能语言 v2：封闭 AST，`run`、`and/or/not`，深度 3，禁止递归，最外层共享预算，完成条件由允许观察判定；无变量/算术/文件/网络。A 与 B 共用。实现验收见阶段 1 各组件报告。

## 实现修订 3 的继承登记（设计 v0.5）

- 观察辅助：`spatial.py` 只消费通过校验的观察 JSON。正前方取 facing 对应格；每类材质/实体按曼哈顿偏移找最近者，平局按 dy、dx 排序；方向写成纵向再横向，步数是偏移量，不保证可走，相邻为四邻一格。可选 9×7 图把未提供格填 `?`，不补全夜间/视野外信息。原始观察规格仍为 v1.1，辅助数据放在提示词独立的 `observation_aids` 字段。三种格式由 G0p 预登记比较后选择。
- `goto('material/entity')` 是 D2 的继承宏，也是一种共用决定和技能语言操作；没有模型专有版本。BFS 的输入只有当前 JSON，不持有环境/地图句柄；每步重新观察。材质 grass/path/sand/lava 且无占位实体才预测可走，来源是按键移动的固定出生配置；目标不可见、无路径、阻挡、净掉血、结束、接管或预算耗尽立即停止。不存在免费转向：搜索状态包括朝向，底层移动全部记步。它不执行采集/制作，也不记住视野外位置。
- 规则卡格式改为 rule.v2：全部为跨世界规则假设；来源保留经历 ID 及证据世界，支持/反例按实际证据世界分开计数。地图与世界型项目继续限域。历史修订 2 数据库不迁移、不用于新练习。
- 写入由程序核对同动作证据，至少一条满足新卡前提且所有适用引用的预测正确；不适用的同动作记录只用于界定前提/旧卡反例，不计支持。替换还必须引用对旧卡适用且预测不符的真实记录。模型不能提供计数或作用域选项。
- 睡眠输入包含程序从允许轨迹抽出的最多 4 段可见增益动作序列及可见计数完成条件候选；不预置技能内容、不传奖励/成就/隐藏配方。两组获得相同的经历选择与序列材料。B 提议技能并经封闭语言和来源校验保存；A 仍写文字反思。记忆字节上限保持相同。

工程证据：`evidence/phase1/revision3/engineering.json` 及组件报告。G0p 最高候选前方识别 25/30，未达 90%，已停在该闸门；云端技能整理未验证，工程替身不证明真实模型会提炼技能。详见 `evidence/phase1/G0.md`。

## 修订 3 第二轮继承登记（设计 v0.6；提示词 v3.1）

本段替代上一轮表示和 goto 的当前行为；旧 G0p 证据与 K0 对照保留原样。

- 表示 v2 只在发给模型时转换。自己另列 self（脚下材质、中文朝向与向量）；格子列表不含 (0,0)，最近每类东西排除自己与脚下，偏移步数从 1 起。front 带朝向、偏移，空实体为 none。小地图中心为 @，图例描述“你自己，面朝某方向”。无格子列表的格式仍另列所有允许的植物成熟与箭方向状态。夜晚不补格。历史变化里“移动后被自己占据的格子”仅在发送视图中用 self 表示，原始变化与内部观察不改。
- A/B 每次输出第一个字段为 front_seen（材质、实体）；严格检查实际 JSON 字段顺序，按当前允许观察计分、写入轨迹。错误不纠正、不重问，合法决定仍执行；非法输出沿用连续两次停止。答案选项未删 player。
- recent 仅含决定类型、动作/技能名、执行状态与步数；旧理由、源码、front_seen 均不回传。理由继续完整记入轨迹。
- goto 规划可走材质改为 grass/path/sand，lava 永不作为移动或碰撞转向的目标格，但仍可作为接近对象。BFS 加入朝可见障碍/实体按移动键的原地转向，真实执行 1 步；计划内转向不触发宏的 blocked 停止，意外阻挡仍停。原始变化感知仍如实报告零位移，规划记录区分计划内转向。全部搜索只读当前允许观察。
- 只给 B：每次决策核对自己所有规则卡的前提，完整核对结果入轨迹；相关候选动作的白话卡片预测优先进入原有相同记忆上限。逐项显示当前条件、支持/反例数及正负/零变化；前提不满足时仅说“没有本卡所列效果，其他后果未预测”，不凭卡片发明一般失败原因。A 无此组件。规则真值统计与写入校验未变。

工程验收与限制见 `evidence/phase1/revision3_round2/ENGINEERING.md`。G0p2 之前不据此宣称模型已经读准；K0 为旧 map，只作对照，K1/K2 的选择与通过判据另行冻结。
