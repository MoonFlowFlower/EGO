# 观察契约 v1（P1，阶段 0）

自定义结构化 Crafter 任务；不能与原版 RGB 基准直接比较。

## 信任边界与允许字段

可信游戏驱动 `Host` 是传感器与执行动作的边界。只有它可访问环境；仅在采样玩家附近格子、读取 HUD、计算位移差时使用内部状态。它不构造/传出全图语义地图。策略、观察消费适配器、技能解释器只能得到经过白名单重建的 JSON。Python Host 对象从不交给生成的程序。

允许：`schema` 固定值；`tick` 已执行底层步数；`world` 随机不透明身份（不含 seed/规则）；`needs` 的 health/food/drink/energy（0–9）；12 种背包物品计数；`light` 四位小数；`radius`；局部 `cells`（dx、dy、material、entity）；`displacement` 上一底层步真实位移差；`facing` 朝向；`sleeping`；`done`；固定全部 17 个动作的公开名称。基础动作不按当前可行性筛选。

位置选 A：真实位移差传感器。继承该额外能力，阻挡时差为 [0,0]，不暴露绝对坐标；累计路径是她可自行维护的相对地图。朝向属于可见姿态，单独登记。

夜晚规则是人工设定的可见性，不声称和像素可辨性相同：light ≥ 0.5 时 dx ±4 / dy ±3，共 63 格；0.2 ≤ light < 0.5 时 ±2，共 25 格；更暗时 ±1，共 9 格。边界外返回 unknown，不告诉地图尺寸。不实现遮挡；原版画面也显示局部全部格子。实体只给可见种类，不给 HP、计时器、目标或隐藏状态。

禁止：全图、绝对坐标、环境对象、RNG、seed、规则参数、奖励、成就名称/分数、配方/前置条件、可行动作筛选、oracle 失败解释、隐藏地图和评估器反馈。失败只报输入不合法/已结束等边界错误，动作结果通过允许的前后观察看到。

## 全系统审计清单

| 通道 | 处理 | 当前证据/后续检查 |
|---|---|---|
| 观察 | 白名单重建，不转发 info | P1 测试；局部读取仅在可信驱动 |
| 夜晚 | 先裁剪后序列化 | 63/25/9 格实测 |
| 位置 | 只发位移差/朝向，世界 UUID 不含参数 | 阻挡位移实测 |
| 动作名、背包名、格子名 | 变体使用同一公开别名表，全部动作始终列出 | P1 全别名烟测；P4 再测成对世界 |
| 成就、奖励、失败解释 | 不进策略上下文 | 只放 owner/evaluator 通道 |
| 技能源码、权限 | 只收受限语言，拒绝 import/属性/文件/网络 | P9 实测后补证据 |
| 错误及日志 | 不发 traceback、原始请求、配置或路径给模型 | 后续 runner 仅发稳定错误码 |
| 世界状态、记忆、索引、缓存 | 绑定不透明世界；私密参数不进入技能/检索 | P6 检查 |
| 变体生成器、测试名称 | 留在 trusted host；不发种子/配置/变体类别 | P4 检查；正式 E1 密封抽样未实现 |
| 模型提示词与供应商请求 | 仅游戏观察、允许的动作、必要短历史 | P2/P3 出站结构再次审计 |
| 观察台、接管、回放 | owner 单向显示；只有动作能反向进入执行器 | P10 检查；教学标注 |
| 示范 | 不直接转发上游 npz；重建允许字段 | P5 准备并由负责人录制 |
| 个人资料、凭据 | 不进入游戏上下文；凭据只在服务端 | P2 安全读法与出站白名单 |

继承：17 动作的含义、局部符号识别、HUD、朝向、真实位移差、昼夜传感器、8 步封顶直线宏（看到目标/阻挡/结束即停，无隐形寻路与自动脱困）、运行时随机数修复。配方知识可由基础模型已知；此处不注入配方答案。

本清单覆盖计划通道，尚未建成的通道不能因列在表中而宣称已通过审计。正式实验前需要对完整系统再次审计。
