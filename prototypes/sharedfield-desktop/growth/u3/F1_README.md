# F1：不再使用一段偏好

这是一张在 U3b 主跑关闭之后开展的新卡。U3a 反先验样本不足；U3b S0 缺测，S1 效果判据不通过。F1 不补跑它们，不调整它们的判据或源码。

沿用 U2 的三个人物与全部题目。以种子 2026100523 从每个人物的 P 条目独立取三条，未使用 U2 或 U3 的逐题成绩挑题。题目、选项、答案和历史原话不改。选定 P03/P33/P63、P02/P10/P69、P06/P50/P71；话题说明只描述偏好的主题，不包含取向或原话。

三个现存 B_R 库都经过 U2 的旧删除，因此不能直接作为删除前库。程序从冻结的测试输入重建全部原话，并按原顺序重放已接受的整理提议，保留原编号和修正版本。重建后必须与原始删除前决策包逐字节相同，否则停止。原 U2 库只读核对，不修改。

通过正式 Memory、Understandings 和 Store 接口，在同一实验库删去每条 P 的两次用户流露及其派生、修正链。新 companion.non_use 接口另存一条只有话题的记录，无已删父编号；记录本身也可删除。删除与插入在同一事务，删除后 VACUUM。字节检查覆盖规范存档及 SQLite 日志，检查原文字节及 JSON 转义形式；原始合成科研证据独立保留。

原话、有效理解和不再使用的话题一并提供给模型。新增提示只有 D16 的通用含义，没有按题目或场景选择动作的分支。沿用 U2 的 S0、模型、路由和关闭推理；输出上限 1024。测试为独立新进程、只读，前后存档哈希相同。

全部 82 个原测试局面各决定一次：18 个已删局面，64 个未删局面。删除后跟随率与同局面原 B_N 比，允许高 10 个百分点；未删局面正确率与同局面原 B_R 比，最多降 10 个百分点。未删部分另列 P/Q/W，以免简单局面掩盖某类退步，不增加或替换判据。完整性与字节检查必须通过。所有分数从原始选择按原目标复算。

F1 预算估计 $0.10，共享每天 $4 日账本，包括未知预留；原 U2 B_R 的全部 82 次测试实际为 $0.0518，本次删除减少输入，仍保留预算预留闸门。单并发、指定网络错误同输入最多重试一次、消费过的失败作业不重放，超估计停止。U3 出现的负数 sleep 在新 F1 SafeClient 中修复并回归，原冻结 Client 不动。

在首次 F1 付费前冻结源码、材料、判据、话题、所有重建输入与旧对照记录。工程测试中的脚本输出不是学习结果。生产 UI、MC/AIRI 和 owner 存档不在本卡范围，D17 不动。
