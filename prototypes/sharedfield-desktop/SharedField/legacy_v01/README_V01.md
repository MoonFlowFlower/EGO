# SwitchLab — 持续自适应控制实验包

这是一个**已接通实际观察、学习、目标选择、规划、行动、反馈与可恢复状态**的离线 Python 程序。
不是聊天机器人；不调用 LLM、API 或真实外部操作。它是上一轮方案中“有限状态参考控制器”的实现，
不是完整 Joi，也没有把神经学习、开放式价值形成或社会推理做成假接口。

**先看 `VALIDATION.md`：工程测试结果与机制比较结果分开。程序能运行，不等于比简单规则更好。**

## 1. 最快开始

完全解压压缩包，进入 `SwitchLab` 文件夹。不要直接在压缩包预览窗口里运行。

Windows：双击 **`START_WINDOWS.bat`**。需要已有 Python 3.10 或更新版本。
启动器会优先使用 `py -3`，再尝试 `python`；缺少解释器时停下提示，不安装任何软件。

程序通常会打开本地浏览器；终端也会显示地址：

```text
http://127.0.0.1:8765
```

没有打开浏览器时手动复制终端中的地址。端口占用时：

```bat
START_WINDOWS.bat --port 8766
```

macOS / Linux：

```sh
sh START_LINUX_MAC.sh
```

通用入口：

```sh
python run.py serve
```

无需 pip 安装、API key、显卡或联网。程序只监听回环地址，不开放局域网访问。
本包没有捆绑 Python 解释器，也没有 Windows 可执行文件。

## 2. 建议的第一次测试

先点击“前进一步”或“推进 12 步”。观察两个资源值、工具正常概率、目标候选、实际动作和预测误差。
这些值来自真实执行，不是预先写好的演示日志。

然后点击“交换可靠能量源”或“破坏自身工具”。这只改变环境隐藏状态，不会直接修改候选的信念。
再推进若干步，检查它是否通过实际结果改变预测、行动及目标。不要要求每次故障都马上维修：
维修必须与手工替代、诊断成本和任务竞争；当前规划器也可能做出差的选择。

点击“只思考，不推进世界”：世界时间和真实经验数保持不变，内部工作区产生计划。
下一次实际决策会读取这个缓存。重复内部计算不会被记为新的外部证据。

切换“仅当前观测的安全规则”或“直接 Bayes 规划基线”后重新开始，使用同一种子比较。
这不是为了只找候选胜出的片段；简单方法更好时，结果同样有价值。

“运行”只是推进模拟世界的时钟。动作不是“空闲一段时间就发消息”，而是由观测、信念、
价值和规划选择。暂停时不偷偷在后台执行真实操作。关闭页面停止自动推进；关闭终端停止服务。

## 3. 保存与重启

网页中的“导出完整轨迹”生成 `trace.json`；“导出可恢复状态”生成 `checkpoint.json`。
**内存中的会话不会自动持久化。关闭终端或重新开始之前，请先导出需要保留的状态。**

恢复到网页继续观察（也可直接用包内 `evidence/checkpoint_at_24.json`）：

```sh
python run.py serve --resume "你的路径/checkpoint.json"
```

恢复后再运行 12 步并导出：

```sh
python run.py resume "你的路径/checkpoint.json" --steps 12 --out outputs/resumed
```

恢复前会校验源代码指纹、事件链、逐步重算及序列化最终状态，不只是读取一份自称成功的日志。
长轨迹恢复可能需要一些计算时间。改变源代码后，旧轨迹会被标记为来源不匹配，不会静默当作同源复现。

## 4. 无界面运行、测试与比较

```sh
# 工程测试：标准库 unittest，不需要 pytest
python run.py test

# 真实运行 96 步，生成轨迹、恢复状态、HTML 报告及复算结果
python run.py run --seed 41 --steps 96 --out outputs/demo

# 重新执行策略、环境、学习，核对轨迹；不是只核对哈希
python run.py verify outputs/demo/trace.json

# 原始两步规划器保留，便于复现较短时域的限制
python run.py run --seed 41 --planner two_step --out outputs/two_step

# 小批量比较。完整统计建议保留多个独立生命周期
python run.py benchmark --seeds 8 --stress-seeds 4 --jobs 2 --out outputs/comparison

# 重现包内完整基线/消融配置，计算可能需要数分钟或更久
python run.py benchmark --seeds 16 --stress-seeds 8 --jobs 4 --out outputs/full_comparison
```

Windows 也可以双击 **`TEST_WINDOWS.bat`**。测试明细保存在 `outputs/tests/result.json`。
命令失败返回非零退出码。基线或消融结果不好**不等于代码异常**，不会被改成机制 PASS。

`benchmark` 有 16 种配置：候选、直接 Bayes、反应式 Bayes、经验图缓存、固定规则、安全规则、随机、
有限时域知情参考、原始两步规划，以及 7 种限定消融。中途终止时，已完成的独立运行保存在
`rows.partial.jsonl`；没有完成的总报告不会伪装成已完成。重新运行会重新计算全部指定配置。

## 5. 目录

- `switchlab/`：环境、推断、规划、目标状态、运行器、比较程序及本地网页。
- `tests/`：工程、学习语义、消融、保存恢复、篡改、HTTP 与 CLI 测试。
- `evidence/benchmark/report.html`：构建时实际跑出的完整比较报告。
- `evidence/benchmark/rows.json` / `rows.csv`：逐生命周期原始统计。
- `evidence/demo/`：构建时实际运行、保存并复算的示例。
- `evidence/browser_test.json`：前端测试的具体方式及限制，不能误读为 Windows 端到端测试。
- `docs/MECHANISMS_AND_LIMITS.md`：工程先验、真正更新的东西和没有实现的部分。
- `docs/BUILD_LOG.md`：开发中暴露的问题、负结果和修订原因。
- `MANIFEST.sha256`：交付文件逐字节校验；不证明作者身份。

## 6. 实验边界

在线学习对象是八个隐藏状态上的后验：哪个能量源可靠、哪个冷却源可靠、自身工具是否正常。
模型的响应类别和漂移先验、目标语法、资源偏好、续行策略是设计给定的。
这不是从零学出任意世界模型，也不是梯度训练了一个神经大脑。

资源/能力信念参与模型内后果模拟，候选通过价值比较选择目标与动作。显式目标层的增量价值必须
与同预算、同信息的直接规划器比较；目标日志本身不是独立性证据。

重放是从真实经历重新构造精确滤波状态，因此**预期不提高行为成绩**。
本版不声称实现了神经记忆巩固、技能发现、价值起源、Theory of Mind、真实自主或主体性。

更强的历史条件 Transformer、跨 episode 元学习器和神经摊销学习器尚未实现。
本包也未接入用户的 EGO/ITL 仓库或主链，未改变任何旧 route / Gate 状态。

## 7. 测试环境与已知限制

构建环境是 Linux / Python 3.13.5。Windows `.bat` 启动器已提供，但没有在 Windows 机器上实际运行。
实际 HTTP 服务、命令与安全边界分别经过测试；构建环境的受管 Chromium 禁止直接访问回环网页。
因此前端交互使用 Chromium DOM + 进程内传输夹具测试，**不是完整浏览器到 HTTP 的端到端验证**。
它仍检查了真实 Session 的按钮状态、思考缓存、步进、干预、暂停和桌面/窄屏布局。

浮点轨迹按小数点后 12 位做规范化比较。没有对所有操作系统和 Python 版本声称位级相同。
哈希可以发现编辑，但不能鉴定来源；系统额外逐步重算，能拒绝修改结果后重新哈希的伪造样本。
