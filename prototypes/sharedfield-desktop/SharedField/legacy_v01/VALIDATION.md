# SwitchLab v0.1 — 实测结论与交付边界

## 结论

**本地工程闭环已实现并经过测试；复杂候选的比较优势未成立。当前应停止扩张这套复杂架构，而不是把负结果调成 PASS。**

它可以观察、更新信念、进行内部计算、比较目标、行动、吸收反馈、保存恢复并逐步重算。
但当前候选在标准与压力情境都低于安全规则和反应式 Bayes 基线；显式目标层没有得到有益增量的证据。

## 1. 实际执行的检查

- 标准库 unittest：**60 项，0 失败、0 错误、0 跳过**。原始记录：`evidence/final_tests/result.json`。
- 完整比较：**16 种配置 × 24 个情境—独立种子生命周期 = 384 组运行**，每组 96 步，共 **36,864 步**。
- 标准种子 101–116，共 16 个；压力种子 1001–1008，共 8 个。压力是参数失配，不是结构 OOD。
- 保存恢复：从第 24 步的序列化 checkpoint 恢复，再运行到第 36 步，后续决策、环境转移和更新相符。
- 逐步重算：96 步示例与含内部计算、测试干预和记忆重放的轨迹均重算通过。
- 篡改：原始 hash-chain 篡改与“改结果再重哈希”均有拒绝测试；不声称密码学来源认证。
- HTTP / CLI：实际本地服务、写请求边界、命令、JSON 导出、任意路径拒绝、带空格工作路径经过测试。
- 前端：Chromium DOM + 进程内真实 Session 传输夹具，7 项交互/布局检查通过。**不是完整浏览器 HTTP 端到端验证**。
- 构建环境：Linux / Python 3.13.5；Windows 启动器和 Windows 浏览器没有实际执行证据。

## 3. 能支持什么，不能支持什么

固定同一观察流上的预测检查，平均负对数似然（越低越好）：

- `candidate`：0.551549。
- `freeze_learning`：0.683872。
- `memory_reset`：0.683872。
- `no_self`：0.571435。

这支持：本版的有限模型族更新会利用经历，改变预测；冻结或清空该状态会失去相应收益。
这不支持：该学习方式新颖、所有智能都需要显式 self-model、完整候选优于更简单控制。

`no_goal_commitment` 与 `flat_bayes` 在本实现中等价，不应把这两个名字当成两份独立机制证据。
`no_replay` 的回报与完整候选逐种子相同，这是精确重算的预期结果，不是隐藏成功。
长时域想象虽然产生了诊断/维修行动，但当前并未形成更高净收益；“想得多”不能冒充“想得好”。

尚未完成：历史条件 Transformer、跨 episode 元学习器、神经摊销学习器、学习型程序技能、
神经巩固、社会 ToM、未知模型结构发现、学出的价值起源、真实软件主链接入。

## 4. 接线、权限与 STOP

| 项目 | 已观察状态 |
|---|---|
| 当前层 | 独立离线工程实现 + 有限族 Bayesian latent-state adaptation |
| 本地接线 | run.py → Session.step → decide → World.step → learn → 后续 decide |
| 启用状态 | 需要用户启动 CLI/网页；导入模块不自动启动 |
| 真实触发 | 包内 demo 与 intervention_trace 记录实际调用、状态变化与后续行动 |
| EGO/ITL 主链 | 本包未接入；用户仓库及既有 route 当前状态未读取 |
| 外部权限 | 只有有限 toy actions 和本地用户请求的导出；无真实软件操作能力 |
| 声明上限 | 该源码与 trace/replay 合同下的有界离线功能观测；机制优越性未成立 |
| STOP | 暂停复杂候选扩张；不因其能运行就加上 LLM、社会模型或更大记忆 |

用户侧下一步是验收实际启动、故障后行为、保存恢复和同种子基线对比；这不自动授权重启任何旧研究路线。
