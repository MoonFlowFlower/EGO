# SwitchLab Studio v0.3 — 对话进入可塑控制回路

本轮授权：用户要求继续完善其已测试的独立 SwitchLab 包，不接 EGO/ITL，不扩展外部权限。
目标不是装饰计数器，而是使同一组语言候选的选择可被真实经历、冻结学习、删除经历改变。

## 已复现根因
v0.2 Core.message 仅写入文本；Core.turn 只提交 LLM 文本/记忆/任务。普通对话不经过模型预测、误差、梯度或动作仲裁。工具贝叶斯世界的 tick=0 是该世界没有实际动作的准确记录，不应该随聊天伪增。

## 实施边界
延用 HTTP、provider、持久任务和旧玩具环境。默认入口升级为 AdaptiveService/AdaptiveCore；原类保留为 v0.2 回归参考，不作为并行控制器运行。
一次对话两次语言调用：analyse（来源约束的观测与开放文本候选）→ 本地可训练网络预测/排序 → express（只表达已选动作）。无静默降级为普通聊天。
网络：纯 Python 单隐层 tanh MLP，80 输入、24 隐藏、27 输出。前3头预测用户报告的任务/约束/理解结果，后24头预测下一真实观测的哈希特征。共享隐藏层，不声称统一人类社会世界模型。
每个实际新观测先与事前预测比较，再更新，绝不先看答案再记录预测。工作痕迹是工程递归状态，神经权重是真实梯度更新。反馈标签必须显式确认；赞同和重复不提供事实真值。
记忆：有界 reservoir、独特样本ID、在线更新和有预算的实际重放梯度；重放不增加证据计数。事实图按 holder 分离 user/other/self/world，有原文来源、冲突保留；语义抽取未认证。
目标：候选内容由 LLM 生成，有限计划与权限由既有内核约束。选中目标在表达成功后提交；中断/暂停丢弃未表达决定。已执行结果用于后续策略学习。最终价值权重仍是工程先验，不称开放式终极价值起源。
迁移：不覆盖旧目录，显式 v0.2 轨迹复算后导入；历史标 legacy，神经学习从新经历开始。不更改旧数据哈希来假装兼容。

## 验收
消息进入：认知观测计数与工作状态更新；玩具时钟不变化。
事前预测→下一个真实输入→预测误差→梯度→下一候选评分，均有事件ID与参数摘要。
相同候选不同已确认经历可改变选择；冻结后不能改变权重；重复回放不冒充新证据；坏标签可撤回并从保留样本重建。
语义管线、真实本地HTTP、状态恢复、费用预留/暂停、迁移、UI操作分别测试；测试替身与真实 LLM 实测分开。
合成训练报告包括负结果和简单学习基线；不以训练损失降低宣称现实优越性。

## STOP
无真实 provider 凭据则交付可在用户本机运行的 capped smoke test，不假称已调用真实模型。
不能可靠保存、暂停、隔离来源则阻止交付。神经方案不优于简单方案时保留结果，不再调验收指标。
