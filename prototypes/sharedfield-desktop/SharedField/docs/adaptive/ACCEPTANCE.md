# 当前版本验收映射与审计

没有调用独立审计员/模型。下面是实现者的源码检查和真实测试，不伪装独立复核。

## 路径与对应测试
- 默认入口：run.py studio -> http.serve -> AdaptiveService -> AdaptiveCore。test_adaptive_http 子进程实际启动验证。
- 普通对话：submit -> message -> pending预测对照 -> learner.learn -> analyse -> local score -> express。test_adaptive_core/service/pipeline验证，不靠world tick装饰。
- 外部授权：新增目标只有express成功后提交；实际工作只有有限步授权。暂停、新输入和两阶段失败不提交旧动作。
- 反馈：decision outcome 或artifact feedback ->真实学习；重复标签拒绝；错误标签撤回重建，旧来源明确撤回。冻结数值学习不关闭普通对话。
- 内部计算：真实样本触发一次预算重放，来源矛盾触发一次可处理问题；无输入无价值时休眠。新问题、实际反馈、目标修订影响下一轮上下文。
- 模型边界：声明来自谁、原文是什么；对世界的说法不是环境真值，隐藏toy答案不进入语言提示。
- 保存恢复：事件与数值状态重算，源代码绑定；原子保存失败回滚；恢复暂停。
- 迁移：精确原版v2代码先核对旧记录，旧上下文进入新生命周期，旧目标不自动启用。

## Hard-coding审计
- 工程先验：词汇特征、有限工具协议、3个目标维度与权重、冷启动优先次序、状态递推、冲突触发、有限预算与允许操作。
- 学习依赖：神经梯度、经验匹配、后果预测器误差选择、用户报告条件下的成功率估计、成功计划案例。
- 表现模拟风险：语言回复/意图文本仍可能看似聪明却不改善行动；模型候选只是外生提案。反迎合提示与来源隔离不能当作独立判断机制已经成立。
- 最大简单解释：同模型长上下文或任务清单可能已实现同等效果；本包没有完整排除它。神经输出不优于简单预测器时允许选择简单者。
- Replay合同：模型输出重用为已记录外生输入，只复算后续选择与状态，不认证提供商身份/内容真值，不重新调用同一模型。

## 明确STOP与回退
- 真实模型输出频繁无法满足两阶段协议：停止自动推进，查看错误；不生成假输出或自动付费反复重试。
- 预测质量不优于简单控制：默认经验比较可以保留简单方案，不因神经标签而强制采用。
- 用户觉得更多调用/状态比普通聊天没有净价值：暂停当前扩张，用相同模型、信息、成本做真实比较，而不是增加人格或更多面板。
- 出现权限越界、错误执行、停止无效：停止运行并保留导出；不扩大权限“修复”。
