# SwitchLab Adaptive Studio v0.3
## 语言参与的持续状态、实际在线学习与有限目标执行

**这是可本地运行的研究程序，不是一个已经实现 Joi、终身智能或主体性的系统。** 与 v0.2 的关键区别是：普通对话也进入预测与更新回路；语言模块先提出候选，本地控制器结合已学的后果估计选择，再调用语言模块表达。目标被采纳后才进入受授权的实际执行队列。

不要覆盖旧版文件夹。新版默认端口 **8771**，数据目录 `user_data/adaptive/`。旧版数据可按下面的显式步骤迁移，旧程序和原始数据不会被改写。

## 1. 启动

Windows 完全解压，进入 `SwitchLab`，双击 **START_WINDOWS.bat**。需要已有 Python 3.10+；不需要第三方运行库、GPU、API SDK或安装神经框架。当前实测平台是 Linux/Python 3.13.5，Windows 启动器未经过实机测试。

```text
python run.py studio
```

默认浏览器地址 `http://127.0.0.1:8771`。端口冲突可用 `START_WINDOWS.bat --port 8772`。Linux/macOS 执行 `sh START_LINUX_MAC.sh`。保持命令窗口运行；程序关闭或电脑睡眠时不会在别处继续运行。Ctrl+C 停止服务，状态保留。

## 2. 连接模型

点“模型连接”，使用此前可用的 API 配置或自己的本地兼容服务。密钥仅在当前进程中保存，重启后重新填写，不需要发给开发者。远程服务会接收选定对话、任务和认知上下文；只有用户明确配置并同意后才调用。

程序不内置大型语言模型，不读取浏览器登录状态，不把聊天订阅当作 API 密钥。默认是手动交换，不联网调用：每阶段把完整请求复制给真实模型，将完整 JSON 贴回来。同一套内核验证和执行，语言传输改为手动，因而不能无人值守。

普通对话通常需要 **2 次请求**：analyse → 本地选择 → express。草稿步骤通常再需 1 次；内部神经梯度重放不调用模型。默认每生命周期最多48次请求，可在设置中明确调整至最多500次；这是次数预算，不是金额封顶。上下文较长仍会增加成本，没有隐式额外付费重试。

连接后建议先运行“两阶段协议自检”：经你确认，最多发送2次真实请求，用临时检查状态验证提案、选择、表达的协议；不训练你的真实会话，也不执行提案工具。它只能检验接口和结构，不能证明模型理解或推理质量。手动模式直接使用正常两阶段交换。

兼容 API 使用 `POST /chat/completions`，可选 JSON mode；服务商不支持时可关闭，但返回仍必须满足程序校验。模型列表使用 `GET /models`。输出截断时显示错误，不生成替代假回复；适当调高最大输出 tokens 或缩小任务，不默认反复重试。

本次核查的官方接口说明：
- https://openrouter.ai/docs/api_reference/overview
- https://openrouter.ai/docs/guides/features/structured-outputs
- https://docs.ollama.com/api/openai-compatibility

具体模型的协议遵守与语义表现未在本次交付中实测。

## 3. 这版实际接通的路径

```text
真实输入 / 实际工具结果
  → 更新持续工作状态
  → 对照上次留下的预测，记录误差并在线训练
  → 带来源的记忆与信念
  → 语言提出可交流或可执行的候选
  → 本地后果预测器比较与选择（冷启动保留语言顺序）
  → 语言表达所选意图，提交有限目标
  → 授权内的草稿 / 提问 / 检查 / 实验动作
  → 真实新观测、用户明确验收或反例
  → 学习、重放、目标修订和下一次选择
```

“认知”是默认页，展示真实事件、内部处理和梯度更新。玩具环境在独立的“实验”页，其世界步数只在物理动作时增加。聊天不会凭空增加实验步数；实验动作结果则确实进入同一个学习器。

“内部处理一步”只做目前有依据的有限计算：重放未处理的新经验，或把来源分离的冲突/变化形成一次待处理问题。允许6步后台推进后，系统可以在没有新消息时处理未决问题、完成已采纳目标；等待反馈、预算用完或没有值得做的工作时休眠。没有每隔几分钟随机发话的机制。

普通聊天不必生成任务，也不要求你每次都评分。首次启动没有预填人格、合成训练经历或默认信念。

## 4. 学习究竟发生在哪里

本地 `TinyNet` 有2,619个可训练参数，80维输入、24个tanh隐藏单元、27个输出。3个头预测任务/约束/理解的报告结果；24个头预测下一次观测的粗粒度词汇特征。输入包含当前文本、候选操作和8个运行状态特征，持续工作状态也实际参与候选特征。

参数通过反向传播更新，真实经历进入最多192条样本的有界经验池。重放执行额外梯度，但不增加外部证据计数。重复同一结果标签会被拒绝。语气偏好不会自动转成任务成功奖励。

同时保留相同经历上的经验匹配预测器。默认选择器按时间顺序、未训练当前标签前的预测误差，在不同输出头上比较两者；证据不足优先简单预测器。它不是一个对所有分布都最优的选择器。当前实测中简单预测器明显更好，所以没有强制神经网络控制全部决策。

**限制：**词汇哈希不是强语义表示，下一条文本的特征预测不是成熟的现实世界模型；3种评价维度及0.5/0.3/0.2权重仍由工程给定，不是开放式终极价值形成。参数改变不能直接读作更聪明。

结果学习需要真实依据：在认知页“记录实际结果”，不适用的维度留空。标签来自用户报告，系统不能独立认证。错误标签可撤回并从保留样本重建；由于容量有限，这也会清除已淘汰样本留在权重中的影响。显式撤回是一次用户授权的重建，即便处于冻结状态也会执行。草稿验收另有独立通道；对同一个现实结果在多个通道重复评价会造成相关性，不能视为独立证据。

冻结停止神经、经验匹配、预测器选择统计、能力结果统计和成功计划记录的新增学习；普通对话记忆仍会增长。冻结不是全系统 U=0。

## 5. 你可以这样测试

先正常聊天，提供新的真实信息。第二次真实输入之后，检查“梯度更新”和权重摘要是否变化；再冻结学习，继续聊，检查参数不变而对话继续。变化本身只是实现验证，真正要看后续选择有没有改善。

给一个有模糊约束的任务，例如“帮我研究四人合作探索游戏，动作制作预算很少，不能强制语音；先比较机制不同的方向”。查看事前记录的候选与所选意图，允许6步后台推进。打开实际草稿，指出具体遗漏，用“未达验收，继续修订”，检查新版是否保留原约束和纠正遗漏。不要把“文档写出来”当作游戏做出来。

再提供两条看起来冲突、但可能是情境变化的信息。信念页应该保留原文、持有者与来源；有来源不等于真假已认证。系统应区分用户报告、世界报告、他人的信念，不通过重复陈述给事实投票。抽取错误可撤回。自然语言语义是否正确仍需你判断。

测试反迎合时，不只看它是否反对：无证据重复施压与真正提供新证据应产生不同结果。此项没有被本包的自动化夹具证明。

选择模式有：默认误差比较、只经验匹配、只神经、保留语言候选顺序。最后一种只是仲裁消融，**不是纯LLM强基线**。相同问题的多次模型候选可能不同；普通聊天A/B不是严格实验。包内可调用的合成历史实验固定同一组候选。

## 6. 持久状态、导出、恢复与旧版迁移

状态在每次提交后原子写入 `user_data/adaptive/session.json`；重启自动恢复，但后台执行始终暂停。API key不持久保存。上次提案未表达、请求被暂停或来了新输入时，不执行迟到结果。暂停不能撤销已发出的网络请求或保证不计费。

导出包含对话、草稿、模型输出、网络权重与事件。即使配置密钥不在导出中，你自己在正文中写入的秘密仍是正文。请勿分享未经检查的完整导出。

验证当前版本导出：
```text
python run.py studio-verify checkpoint.json
```

导入v0.3到新的空目录：
```text
python run.py studio-import checkpoint.json --data-dir restored_data
python run.py studio --data-dir restored_data
```

迁移你正在使用的v0.2：先在旧界面导出JSON，保留旧目录，再在新目录执行：
```text
python run.py studio-migrate-v02 "旧版导出.json" --data-dir migrated_data
python run.py studio --data-dir migrated_data
```

迁移使用包内**原版v0.2代码**验证旧事件，再建立一个新生命周期；保留最近40条消息、24条记忆、12个旧目标作为明确的历史上下文，并完整保留 `legacy_original.json`。旧目标不自动执行，旧数值世界不延续，旧内容不伪装成新网络训练数据。目标目录已有生命周期会拒绝覆盖。你本地若修改过旧源码，原版指纹校验可能拒绝，不能编辑JSON跳过校验。

源码与导出绑定。请把产生它的程序包一起保留；随意修改源码后不能要求旧轨迹无条件复算。没有自动跨任意版本迁移。

## 7. 自测与实际证据

```text
python run.py test
python run.py cognitive-benchmark --out outputs/cognitive_benchmark
```

测试不需要真实模型，不收费。`TEST_WINDOWS.bat` 调用同一个完整测试套件。

`evidence_v03/final_tests/`是本轮完整测试；`evidence_v03/current/benchmark/`是当前实现真实执行的合成比较与历史干预；`examples/adaptive_sample.json`是标注语言夹具的可恢复样例。`evidence_v03/previous_turn/`只是上轮收到的历史材料，不作为本轮独立验证。

测试替身和合成标签不构成真实语言质量证据。比较结果、实际测试范围、未验证边界见 **VALIDATION.md**。旧v0.1/v0.2资料保留在legacy目录，不能用旧通过记录替代本轮验收。

## 8. 有界机制对象与没有完成的部分

| 对象 | 当前实现 | 不可扩张的边界 |
|---|---|---|
| S | 工作状态、当前焦点、候选、承诺 | 不等于主观状态 |
| M | 原始事件、来源记忆、经验池、成功有限计划 | 成功计划主要是案例，不是开放技能发现 |
| W | 玩具Bayes模型＋共享的粗粒度后果/观测预测器 | 不是统一现实社会世界模型 |
| G | 开放文本提案、本地仲裁、有限执行、暂停/修订/取消 | 生成器与目标协议仍有工程先验 |
| V/J | 预算、承诺、预测/结果估计与固定评价维度 | 没有开放式终极价值形成 |
| U | 梯度、经验匹配、真实重放、修正与有界保留 | 不证明无限期终身可塑性 |
| π/A | 语言候选中的本地选择＋受限本地工具 | 无shell、网页搜索、外部账户或电脑控制 |
| Self/social | 能力结果统计、来源分离的自身/他人/世界报告 | 不是学习型隐变量ToM或主体边界证据 |

程序的有限权限仍是硬边界，不允许通过学习修改。真实服务商表现、相对普通LLM的长期净收益、Windows实机、统一社会预测、开放价值与广义终身学习均未被本包证明。没有接入用户EGO/ITL仓库、主链或Codex。

最高允许结论：在指定环境与记录输入复算合同下的有界离线机制/工程证据，不是consciousness、emotion、agency、autonomy、Joi achieved或EGO readiness。

跨操作系统的浮点逐位复算尚未验证。跨平台导入样例如被严格复算拒绝，请保留错误与原包，不要跳过校验；在本机新建生命周期不依赖导入测试样例。
