# Shared Field v0.4 — 实际验证与限制

## 本轮结论与范围

层级：engineering implementation + bounded mechanism hypothesis。默认运行路径为 `run.py shared → SharedService → SharedCore → Mind/World`。它是当前交付容器内的实现，未访问或修改用户的 EGO/ITL 仓库、远程工作区或真实电脑。

启动/恢复默认暂停，本地状态报告不联网；用户授予1..600步后，系统按当前预测、状态和目标执行内置环境动作。语言必须单独配置。下面的绿测只证明对应范围，不是意识、真实情感、主体性或整体项目完成的证据。

## 浏览器边界：不是原生浏览器HTTP全链路验证

受管理 Chromium 直接打开本机URL返回 `ERR_BLOCKED_BY_ADMINISTRATOR`，没有绕过管理策略。浏览器实际加载当前 HTML/CSS/JS，通过**明确的进程内测试传输**调用真实 SharedService；实际应用HTTP另由测试客户端验证。该方式不验证原生浏览器到本机连接，也不验证实际HTTP中的CSP执行。

15项界面检查包括：真实地图、提问不制造情感值/物理步、用户动作、发现、无模型自动探索、经历后的状态报告、报告快照、消融、隐藏干预、两阶段手动交换、真实Provider到HTTP模型替身、暂停、新探索保留学习、手机宽度、JS异常。

桌面主截图是实际本地数值状态报告，**没有伪装为真实语言模型**。手动/API阶段的测试文字明确包含TEST_FIXTURE。一次最终组合检查在浏览器阶段超时、未产生完成记录；没有据此宣布通过。随后单独重跑浏览器脚本，得到上述15项完成记录；没有为此修改产品行为或管理策略。

## 机制结论不能越级

- 问“感觉/在想什么”可以读取提问前存在的评价状态、目标和关注；这一点不等于状态具有现象性体验。
- 数值评价状态确实进入风险/信息权重与目标候选比较；同历史干预可改变选择，但不证明这是唯一必要结构。
- 路况、工具能力和发现类型收益依赖真实观察学习。评价函数、先验、目标与调节映射仍是工程指定。
- 社会解释来自模型对真实原文的可撤回抽取；引用连续原文只保证来源存在，不保证解释正确。
- 语言输出state_id正确不保证文字语义忠实；没有独立真实性判定器，也没有真实模型的语义或反迎合测试。
- “回看经历”是已知经历的诊断/重排，不重复计入证据，不是神经重放巩固。旧v0.3小网络不在默认核心。
- `learned_events`是已接收的可学习物理事件计数，不是每次都发生参数变化的证明。实际参数与预测需要单独比对。

离线完整候选平均人工效用 -1.043，平坦基线 -0.082；配对差约 -0.960，描述性95%区间跨零。**没有效率或机制优越性结论**。冻结学习与固定能力的退化仅属于本环境消融。强长上下文/元学习/社会模型基线未覆盖。没有改指标或调参把负结果翻绿。

## 本轮发现并修复的具体问题

1. JSON传输将RNG元组变数组，恢复后表示不一致：统一成JSON-native快照，运输后可复算。
2. 世界改变使付费输出过期后，旧消息票可能触发隐式重试：取消票据；后续语言需要明确新输入，不自动收费重试。
3. 暂停后重新允许探索可能复活已取消语言请求：分离行动权限与语言请求票据。
4. 新探索的关注仍引用上一次探索的事件：记录新观测，以其事件ID作为来源。
5. 第三人偏好可能进入“用户合作偏好”加权：仅holder=user可进入该路径。
6. 无效行动可能消耗环境随机序列：在采样前校验动作和资源。

这些都有对应先红后绿测试。`red_*.log`和中间测试是开发历史，不能当作最终未修复失败；也不能拿旧绿测覆盖新源码。最终权威是当前完整套件与外部交付复测。
