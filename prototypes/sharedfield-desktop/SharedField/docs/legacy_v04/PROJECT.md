# EGO / Shared Field v0.4 — 项目入口

## 真实目标
研究和工程化能参与共同经历、持续形成自我模型、情感样调节、兴趣、目标、预测与行动倾向的系统。核心测试可以直接问感觉、思考、想做什么，再干预其经历/状态并检查行为。不要再次降级为文档任务助手、人格prompt、定时陪聊或关系记忆产品。

## 当前形态
默认 `python run.py shared`。界面中用户与系统在同一部分可观察探索环境行动，默认本地控制，无需模型也能探索和学习。语言模块可配置为解释有来源的用户报告、表达现有状态；它不能创造物理事实、写任意情感分数或取得电脑权限。

## 六项状态
- 层：engineering implementation + bounded mechanism hypothesis。不是主体性验证。
- 接入：本交付包的 shared 入口使用 SharedService→SharedCore→Mind/World。旧studio仍保留作回归参考，不是默认核心。
- 启用：启动后暂停；用户一次可授权1..600个内置动作。默认无API，语言启用由用户配置。
- 触发：实际入口HTTP测试、无消息自动探索、失败/发现更新、状态先于表达、暂停/过期输出拒绝；证据位于 evidence_v04/。真实云语言和Windows实机未测。
- claim ceiling：bounded offline mechanism evidence under a specified environment/trace/replay contract。测试通过不证明意识、真实情感、自主主体或EGO readiness。
- 最小下一步：用户测试共同经历后的自然问答和行为一致性，记录误解/缺口；不根据漂亮语言升级结论，不在无新证据时扩展架构。

## 当前机制不是完全学出来的
固定先验：地图/动作语法、概率似然形式、信息收益目标、事件评价函数、风险与信息权重映射。
学到的：有噪声的路况后验、独立校准后的自身能力、不同发现类型的收益估计。
状态：评价轨迹的持续调节变量，实际参与目标/动作候选比较。
语言：自述/他人报告的来源化解释和状态表达；语义正确性需真人/独立评估，JSON正确不够。
未实现：开放价值起源、通用社会因果潜变量、终身神经可塑性、外部电脑/游戏控制、Jev、语音、身体化视觉。

## 代码定位
- `switchlab/shared/world.py`：隐藏环境与公共观测，只有这里生成物理后果。
- `mind.py`：概率更新、事件评价、目标/候选、跨探索经验、状态报告。
- `core.py`：原子事件、来源约束、先验状态快照、确定性记录输入复算。
- `service.py`：暂停/保存/有限后台/两阶段语言，复用Studio的Provider和文件锁。
- `http.py` 与 `web/`：loopback服务与共享探索界面。
- `experiments.py`：固定效用的同起点基线/消融；不是语言或意识测量。

## 负证据
首轮8种子比较：完整候选在人工效用上落后平坦基线，差值区间跨零；不能声称复杂结构更好。未为翻绿调参。保留full供用户进行状态-行为干预，不把它推荐为更高效控制器。旧v0.3神经负结果保留；这个版本没有把小神经网络强行命名成情感大脑。
