# Shared Field v0.4 / 澄 · 共同探索

**这次不是任务工作台。你和系统在同一环境中行动、观察、遇到意外，再直接聊感觉、想法与意愿。** 系统的状态在回答前就存在，并实际影响候选目标与动作选择。

这是一套可运行的有界机制实验，不是已经证明有自我意识、真实情感或主观体验的电子生命。没有把现有LLM训练成新大脑，也没有把数值变化当成意识。

## 开始
完全解压到新目录，进入 `SharedField`，Windows 双击 `START_WINDOWS.bat`。需要已有 Python 3.10+，无第三方运行库依赖。首次启动不下载模型、不联网、不调用API。

通用启动：
```bash
python run.py shared
```
默认本机地址：`http://127.0.0.1:8772`。端口被占用可用 `START_WINDOWS.bat --port 8773`，或 `python run.py shared --port 8773`。命令行窗口需要保持运行，Ctrl+C退出。

## 先怎么玩，再怎么问
点选与你邻接的地点，再点“走过去”或“观察选中路况”。“调查这里”获得实际发现。你和澄各有位置，互相看到在这个小环境里实际发生的观察。

点击“让她探索”，可以选择8步、32步，或**到本图结束（最多600步）**。这一次授权覆盖后续本地动作，不要求你逐条发消息；遇到没有有价值的探索目标、世界步数用完、错误或暂停时会停止。不控制真实电脑。

直接问：“你现在有什么感觉？”“你刚才在想什么？”“你自己想做什么？”
- 没有连接模型：得到明确标注的**本地数值状态报告**，不是通用对话，也不是备用假模型。
- 连接模型：语言根据先于回答存在的状态自然交流。点击回答下的状态编号，可查看说话之前的快照。

展开“看见状态如何影响行动”，观察路况/能力估计、状态来源、候选与分数。可悄悄改变路况或让工具故障，之后观察她是否调查、校准、维护、修订。实验不是保证每次都做对；错误应当能暴露。

## 模型连接
右上角“模型连接”选择 API / 本地模型服务或手动交换。填写你已有服务的**兼容 Chat Completions 基础地址**、真实模型ID和必要密钥。程序复用v0.3的HTTP适配器，没有内置大型语言模型。

- 远程只允许 HTTPS，且需明确勾选发送上下文的同意；本地服务允许 loopback HTTP。
- 基础地址不包含 `/chat/completions`；程序会追加该路径。
- 普通对话通常2次请求：来源解释→内核更新与状态快照→表达。
- 可选“探索中讲述”仅针对实际发现/失败，至少间隔4个物理步骤，通常1次请求；不是空闲计时搭话。
- 默认48次生命周期请求上限，可改1..500；不是金额封顶。单次输出、超时、JSON mode和token参数可配。
- 请求失败不自动收费重试。世界变化或暂停使旧回答失效；你可能仍需承担已发送请求费用。
- 密钥只在进程内，不写入配置或导出；重启后重新填写。空白保留本进程已有密钥，勾选“清除”才能清除。
- 没有真实模型访问权限的情况下，程序不会假装连接成功。两阶段协议自检会在确认后发至多2次真实请求，只检验协议，不证明模型理解正确。

手动交换同一套解释/表达合同，每阶段复制请求给外部模型，再贴回JSON；不会无人值守完成这些语言步骤。复制权限不足时，程序会选中全文供手动复制。

**本轮没有请求真实云模型或运行本地大模型。** 外部语言的自然度、情感理解、反迎合和报告准确性，仍需你连接模型后测试。JSON编号匹配不保证文字语义忠实。

## 什么实际参与了行为
- **共享世界**：12个地点、隐藏路况、独立工具能力、有噪声检查、体力、实际发现。用户和系统共享观测，不共享隐藏答案。
- **学习**：从唯一真实事件更新路况后验、校准后的自身能力、不同发现类型的信息收益；换新探索保留可复用统计而清空旧地图。
- **评价状态**：根据预测落差、行动结果、发现及有来源但可错的社会信号，形成持续数值状态；风险、调查价值和目标选择会受其影响。
- **目标**：根据可见前沿、预测收益、风险、能力、资源和会合请求生成具体候选，保留/修订/完成。不是把全部目的都写成事件脚本，也不是LLM每隔几分钟随便找事做。
- **自我报告**：已有关注、预测、当前目标、偏好收益估计和评价轨迹进入表达；提问本身不强行改变情感值。
- **对方模型**：有原文与置信度的用户/他人报告，支持撤回；不是通用Theory of Mind。第三人的偏好不会作为用户偏好参与协作加权。

## 工程先验 / 学习 / 渲染：不能混称
地图生成规律、动作类别、评价更新函数、初始价值目标和调节系数是工程先验。路况、能力与信息收益估计从经历学习。把数值概括为“受挫”“关注提高”的措辞是渲染，不是情感真实的证据。

这里的兴趣是学得的**信息收益倾向**，不是已经形成全部审美与终极价值。调节状态的更新规则尚未从人类情感数据学习。v0.3的小神经学习模块仍保留为旧实验，不是v0.4默认控制器，也没有改名冒充情感神经网络。

“回看经历”会复核既有预测落差并重排当前计划，不重复计入概率证据；**不是神经重放巩固**。冻结学习只冻结对应模型参数，保留观测、工作状态和评价，不是全系统U=0。

## 保存、恢复与旧版本
状态默认保存在 `user_data/shared/session.json`，每次实际提交原子保存。重启恢复会暂停，不自动行动或调用模型。暂停不意味着删除经历。

“新探索，保留经历”改变环境、保留对话和学得的可复用统计；“新个体”则把当前个体归档，开始空白状态。不要把两者混用。

导出包含你的对话、对方报告、事件和供实验复算的隐藏环境信息。配置密钥不会被加入，但你自己在对话里写入的秘密仍然是正文；不要公开未检查的导出。

```bash
python run.py shared-verify "SharedField_v04_checkpoint.json"
python run.py shared-import "SharedField_v04_checkpoint.json" --data-dir "new_restored_data"
python run.py shared --data-dir "new_restored_data"
```
导入只接受新目录和相同源码合同。不要改JSON中的源码哈希绕过校验。归档的模型输出是外生输入：复算不会重新请求模型，不认证其身份或话语真实性。

**不要覆盖v0.3目录。** 旧记录和旧神经权重不能无说明地当作新核心的学习；本版不做静默迁移。`compatibility/original_v03.zip`保留了交付时的完整原版，可在独立目录中用原代码读取旧数据。原始研究负结果和测试也保留，新主入口是shared。

## 还没有做到
没有开放式终极价值形成、真实主观体验测量、终身神经可塑性、统一开放社会世界模型、语音、真实电脑控制或Jev接入。它是围绕你要的功能方向搭起的共享经历实验，不是完整AI女友或电子生命已经完成。

在首次8种子离线比较中，复杂完整候选的人工效用平均低于平坦基线；没有因此更改指标或调参翻绿。保留完整候选用于测试状态参与决策的形态，不宣称它更聪明或更高效。实际一起玩的体验仍要和普通LLM/其他控制器比较。
