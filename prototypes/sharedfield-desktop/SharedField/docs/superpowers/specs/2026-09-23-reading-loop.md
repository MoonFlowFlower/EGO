# 共同阅读与可迁移学习

用户已批准完整真实活动闭环。本实现继续使用已有 MemoryService / SQLite / 模型连接，在单一活动内实现实际阅读、纠正、方法采纳、新材料对照和接续；不重做整套认知架构。

保留 v0.6 只读副本。开发目录为工作区 SharedField。Python >=3.10，运行无新增第三方依赖。所有活动事件、材料、成果、反馈与方法均进入同一事务和记录链。原文最大24000字符，按段提供明确引用。模型产物须引用实际提供段落；引用一致不代表推断已被认证。

活动流程：导入用户选择的文本 → 指定问题/阅读方向 → 一次真实模型阅读 → 展示有引用成果和一个待讨论问题 → 用户纠正 → 模型重读并提出方法 → 用户采纳 → 在不同材料上生成两份答案 → 用户在隐藏方案名时评价 → 揭示普通历史方案与历史+方法方案的结果。相同历史、目标材料和输出额度，保留输入与调用费用；方法带来源、适用范围、例外与版本。单次结果只报告单次证据，不声称普遍成长。冻结学习保留新经历，撤回方法不删除原话。

阅读与方法是非参数技能适应，不伪称基础模型权重更新。日常聊天可读取简短的活动状态与方法，获得共同阅读的连续性。独立阅读仅在用户选定的材料/活动内推进，不自行获取私密文件。重启暂停执行，可从持久任务显式继续。暂停、取消、修订使迟到模型结果失效；没有隐式付费重试。

迁移：冻结 v0.6 代码并验证原始存档，在显式导入时保留完整旧来源、人物 ID、状态、调用计数与新迁移合同。源码路径规范化处理 Windows/Linux 差异，不改写输入存档的哈希。删除来源保守清理阅读派生物及导出迁移来源，不能从备份/方法复现。

验收：RED→GREEN 的内核/协议/服务/HTTP测试；全套回归；真实浏览器完整操作；真实模型端到端调用；真实用户反馈与新材料评价单独记录，缺失则不声称真实用户成长已验证。人工夹具不得被写成用户经历。费用实验上限 $1、最多16次，达到任何一项就停止新增调用。
