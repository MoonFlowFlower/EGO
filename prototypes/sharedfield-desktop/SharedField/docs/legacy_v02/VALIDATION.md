## 浏览器限制——不能写成原生端到端通过

构建环境的受管理 Chromium 直接打开本机 URL 返回 `ERR_BLOCKED_BY_ADMINISTRATOR`，没有更改或绕过其管理策略。使用明确的测试传输：浏览器实际 HTML/JS → 暴露的测试 fetch bridge → Python HTTP 客户端 → 实际本机应用服务器。

这验证了 UI 操作与后端变化，但**不验证原生浏览器到本机网络连接，也不验证真实浏览器中的 CSP 执行**。HTTP 响应头和访问限制另有真实 HTTP 测试。截图使用编写的模型响应夹具，不是服务商实测。

## 本轮发现并修复的断链或边界问题

- 已建立目标的原始约束在近期聊天窗口之外也会随该目标进入执行上下文。
- 信息量按观测条件化后的信念计算，避免物理时间漂移让无信息噪声看起来可学习。
- 新约束与暂停使正在返回的旧草稿失效，不再提交其结果。
- 最小连接测试曾可能在关闭之后写回状态；回归测试复现后补上生命周期/代际检查。
- 不完整 JSON 围栏由输入错误处理，而不是未经捕获的索引错误。
- 文件保存失败时内存状态回滚并停止，而非显示已保存。

红/绿历史日志留在 evidence_v02/；最终结论只由 final_tests/ 与当前记录决定，不能把早期红测误当作未解决失败，也不能用早期绿测覆盖新修改。

## 不能由这些结果推出的结论

没有真实服务商密钥，没有请求真实云模型，也没有运行本地大模型。本轮没有测量真实语言模型的语义质量、长期独立判断、对抗迎合、自动目标质量、广义模糊推理或相对普通聊天的净收益。模型响应替身和预先编写的示例**不构成这些能力的证据**。

没有 Windows 实机运行，也没有逐个 Python 版本实机运行。Windows 启动器已经提供，但首次本地启动仍需你验证。

任务统计是基于用户报告的验收，可能偏置；语义记忆是带来源的模型表达，不是真值。目标提案与排序、有限计算预算、异常阈值、工具合同都是工程先验。未训练开放式价值形成、终身神经学习、社会世界模型或统一的自主主体。

## Replay 合同

模型输出作为**已记录的外生输入**保存。复算重新执行后续状态转移与真实数值环境轨迹；不重新调用远端模型，不认证模型身份，不证明输出内容真实，也不是独立机制审计。源码 hash 是完整性检查，不是第三方签名。旧 v0.1 记录保留但绑定旧代码，应由旧包读取。
