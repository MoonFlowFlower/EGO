# SharedField v0.6 — 连续记忆与跨时间约定

本版将记忆接入默认聊天、后台候选处理和原共享探索，不是只增加一个独立检索面板。长期原话、有效约定、修订历史和学习结果存在本地 SQLite；LLM 每次只读取有预算的相关工作集。

**范围：有界工程实现与局部学习实验。不是无限记忆、终身神经学习、开放价值起源、真实意识或完整 Joi 的证明。** 真实语言模型的理解和表达质量需要在你的服务上测试；自动化测试的语言输出明确为测试替身。

## 1. 启动

完全解压到新文件夹，进入 `SharedField`，双击 `START_WINDOWS.bat`。不要覆盖 v0.5 的目录。

需要已有 Python 3.10 或更新版本。运行不依赖第三方 Python 库，不下载模型，不安装服务，不读取浏览器凭据。

```bash
python run.py memory
```

默认打开 `http://127.0.0.1:8774`。保持命令行窗口运行。Linux/macOS 使用 `sh START_LINUX_MAC.sh`。端口冲突用 `python run.py memory --port 8775`。默认数据在 `user_data/memory/`。

启动和恢复均为暂停状态；普通聊天会处理本轮输入，但程序只有在你点击“允许后台处理约定”之后才会无新消息地检查约定。关闭程序或电脑睡眠期间不会工作，也不会补造已经做过的事。没有安装操作系统常驻/开机自启服务。

## 2. 首次连接语言模型与时区

右上“模型连接”，选择“已有 API / 本地兼容模型”，填写此前可用的兼容服务地址、模型 ID 和必要密钥，确认发送所选上下文。也支持手动交换：复制真实请求给你自己的模型，再贴回完整 JSON。

**默认本地模式没有语言模型。** 它保存原话并给明确标注的状态报告，不能理解任意自然约定。自然交流要连接模型；右侧“＋”是维修用的明确写入入口，不用它冒充模型理解。

时区默认 UTC。选择实际 IANA 时区（例如 `America/Winnipeg`）或明确的固定偏移（例如 `UTC+08:00`），然后保存。Windows 缺少 IANA 时区数据时会显示错误；可自行安装 tzdata，或用固定偏移。固定偏移不会自动切换夏令时。

API 使用兼容的 `/chat/completions`，仍需模型返回协议 JSON。鉴权、限额、网络或结构错误会明确停止，没有生成假回复或隐式付费重试。密钥只存在当前进程，重启需重新填写。

通常一次聊天两次模型请求：解释并持久化，再表达。需要进一步查原文时最多再两次。后台一项到期候选通常一次请求，模型选择延后时以后可能另有请求。

默认初始额度48次。右上可明确追加请求额度，已使用次数不因重启、换模型而清零；首次追加之后按累计授权上限计算，初始额度字段不会覆盖它。次数不是金额封顶。点击暂停不能撤回已经发送的网络请求或保证不计费。

记忆工作区默认18,000 UTF-8字节，可设6,000—60,000；这是可测字节上限，不是假称精确 token 预算。当前完整输入另行保留并发送；必要信息超过总字节边界会停止，不默默剪掉约束。远端模型实际窗口仍需你按端点配置。

## 3. 先用这条完整链测试

1. 自然说“以后一起读《小王子》，时间还没定”。应当轮保存原话；模型正确解释并内核采纳后，右侧出现时间未定的有效约定。没有日期不应偷偷安排提醒。
2. 再说“把一起读《小王子》改成1分钟后”。看它是否更新同一个约定，而不是另建一个。若对象或时间不清楚，应自然核对。
3. 换话题，再问“我们说好的书是什么，现在约的时间是什么？”确认它使用有效版本并能读回原话。
4. 开启后台处理约定，停止发消息。到期后程序在应用内形成联系或有依据等待。没有短信、电话、站外推送；关闭浏览器后本机程序可继续，之后打开能看到已保存的消息。
5. 再测试取消、延后、重新启动。取消的旧版本不应继续联系。一次版本不会因为循环检查而重复发送。

别把“她说记住了”当唯一验收：需要看到真实写入、有效状态、旧版本失效、重启后的召回与条件到来时的处理。

普通界面保持交流；需要核对时进入“记忆维护”，可以分页查看历史、检索原文、展开版本、查看本轮工作集、冻结学习、重建索引或删除错误来源。模型可提出补充查询，并按窗口读取较长原文。

## 4. 本版真正接通的变化

- 原始对话与实际模拟事件增量写入SQLite，不再每条重写一生的JSON；无5,000事件换个体上限，仍受磁盘与运行资源限制。
- 来源、人物与个人/故事/假设/共享小世界的语境分开。模型说过不自动变成实际经历。
- 约定有来源、ID、版本、提出/采纳/待澄清/完成/取消等状态；改约旧输出不能覆盖新版本。
- 最近对话仅是工作集的一部分。检索使用中文单字/双字片段与英文词的FTS索引，补齐关联当前状态；支持原文窗口、查询改写与全集分页。**本版没有部署语义向量模型**，不能保证所有释义都能召回。
- 后台索引与聊天窗口分离。时钟使相关约定进入候选，明确忙碌信息、历史结果及语言判断影响等待或联系。一次版本只提交一条应用消息，跨约定最短间隔120秒，防止重启后积压瞬间刷屏。
- 已逾期超过24小时的约定进入核对用途；不是声称离线期间已经联系，也不会以未回复断言事故。
- 一条局部适应路径：用户明确反馈这次联系“方便/不方便”后，默认类别后验影响未来同类联系是否先有限延后；这不是好感奖励或真实情绪识别。
- 小型在线梯度预测器保留作实验；比较中简单计数更好，因此实际默认使用计数预测，**自动梯度重放关闭**。维护中重放只增加梯度计算，不增加独立经历或重复更新默认计数。冻结学习不删除真实新输入。
- 原共享探索仍作为同一个体的环境，通过“共同探索”打开。换地图不删除个人对话和约定。它仍是离散实验环境；新默认主线不是扩大地图。

## 5. 什么还没有完成

没有真实模型端到端语义评测；中文含糊、反讽、玩笑、条件约定和对象消歧仍可能解释错。精确引用存在只证明来源，不证明理解正确。时间解析支持一个明示子集：明确带时区ISO、今天/明天/周几加具体钟点、数字秒/分钟/小时后等；“明天下午”“以后”没有准确钟点时保持未定/待澄清。

该版没有一般性的自主读书/资料获取技能、语义向量检索、自动层级语义巩固、开放式价值形成、终身神经可塑性或统一社会世界模型。没有语音、Live2D、MC、Jev或电脑控制。没有扩大外部权限。

新默认日常语言路径收到实际共享世界快照，但没有继承为“全面语义检查器”；不能保证语言的所有动作、情感或事实表述都与底层一致。旧v0.5有限措辞检查仍可在旧`shared`入口查看，旧测试通过不等于新语言语义受认证。

持续约定与数据库管理是必要基础设施，不被包装成动机或主体性。整个目标仍是持续学习系统，不因本版记忆可用而把项目终止在RAG聊天或关系记忆产品。

## 6. 接续旧经历

右上“接续旧经历”可导入v0.4/v0.5原始导出，或本版本v0.6导出。当前目录已有经历时需确认先备份再替换；旧文件不修改。原始旧运行用包内冻结代码验证；未保存的真实日期保持未知，不能猜日期。历史调用计数保留，旧未完成请求不会自动发送。

```bash
python run.py memory-import "checkpoint.json" --data-dir "continued_memory"
python run.py memory --data-dir "continued_memory"
```

原共享探索的实际位置与学习状态保留，个人层使用长期存储。导入的旧运行不是新模型能力证据。旧协议也不能自动变成真实生活事实。

通用程序包不包含你的私人对话；另行提供的个人续接文件含你的对话与经历，请勿未经检查公开。

## 7. 保存、备份、导出和删除

实时状态在 `user_data/memory/memory.sqlite3`；`-wal`和`-shm`可能伴随运行出现。运行时不要只复制一个可能未合并的主文件。使用“建立本地备份”获取一致性SQLite快照，或“导出”获取带记录输入链的JSON。

```bash
python run.py memory-verify "SharedField_v06_checkpoint.json"
python run.py memory-restore "memory_backup.sqlite3" --data-dir "restored_memory"
python run.py memory --data-dir "restored_memory"
```

SQLite备份恢复只允许相同运行源码版本并写入新目录。JSON导入也绑定源码；未来版本应有明确迁移，不能原地改代码后绕过校验。界面JSON导入最多128MiB；更大生命周期宜使用同版本SQLite备份而不是一次性导出大JSON。

记录与备份都是本地明文，不含配置字段里的API key；如果你自己把秘密粘贴进聊天正文，那仍是正文。远端模型已经收到的内容无法由本地删除操作撤回。

删除某原文会保守清理其衍生记忆、表达与索引，重置联系结果学习器，并删除本程序管理的本地备份。删除旧导入/共享世界来源时会清空其历史归档与世界快照，避免间接再现，其他不相关原话仍保留。请阅读二次确认，不把删除当普通编辑。

删除会把旧记录链替换为明确的隐私检查点：删除后的输入可以复算，删除前的完整执行链不再保留。检查点只做结构与一致性检查，不是外部真实性签名。已复制的导出、系统备份和远端内容不受控制；没有承诺磁盘取证不可恢复或模型参数彻底遗忘。

## 8. 自行验收

双击 `TEST_WINDOWS.bat`，或：

```bash
python run.py test
python tools/memory_benchmark.py --events 10000 --out outputs/memory_check
```

测试只使用本地数值环境和明确的语言替身，不会请求真实付费服务。可将事件数改为100000；需要相应磁盘和运行时间。基准不等于完整LongMemEval/LoCoMo，也没有证明比同历史全文检索+承诺表更聪明。

浏览器开发检查需要额外Playwright，仅开发者使用；普通运行不需要。此构建环境禁止原生Chromium访问回环地址，所以界面测试使用明确传输夹具，HTTP另测。详见 `VALIDATION.md`。
