# 权限、存储和可复算合同

本包无外网请求、遥测、API key、shell 执行动作和文件管理接口。
除用户指定的本地输出与下载文件外，不修改系统或其他工程。
所有模拟动作都在 World 内，候选不能扩大自己的 action catalogue。

网页仅绑定 127.0.0.1。写请求要求相同 Origin、正确 Host 和随机会话 token；请求体上限 4096 bytes，
一次批量至多 12 步。静态路径显式列举，不提供任意文件路径或目录浏览。
这些是本地实验的工程边界，不是面向公网部署的安全认证。不要转发端口到公网。

导出状态是 JSON，不是 pickle，不执行内嵌代码。读取拒绝 NaN、重复键、超大文件。
写文件先完整序列化再临时文件替换，失败不会覆盖原有文件。

trace 包含初始环境私有状态，供外部评测重算；它不应进入普通候选输入。
事件记录顺序是：既有 belief/候选价值/事前预测 → 实际 action/outcome → 后验与记忆更新。
校验不仅验证 hash chain，还从指定源码重算每一个 command、decision、transition、update 和 final state。
checkpoint 的最终状态还要与重算一致，之后从序列化字段恢复并继续。

源代码指纹涵盖 run.py、switchlab Python 模块和网页资源。文档、测试、启动器与证据文件由交付
MANIFEST.sha256 逐字节列出。不存在对用户 repo、Git clean worktree 或远程 anchor 的验证主张。

浮点规范化到小数点后 12 位后用于 hash / 语义比较；checkpoint 保留原始 JSON 浮点。
构建时只测试了记录中的 Python/OS；不同平台的数值一致性仍需当地运行自测。

公开提供 rechain 是刻意的：攻击者能重做哈希。测试证明“改回报再重哈希”仍会被语义重算拒绝；
但攻击者完全重新生成另一个有效运行，不会被这一协议证明为伪造历史。
这不是密码学签名、不可抵赖日志或作者身份认证。
