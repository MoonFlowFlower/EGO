# Shared Field v0.4 — approved-direction implementation specification

用户本轮确认继续在当前会话实现并打包。保留运输/保存/权限基础；替换任务中心，围绕共同经历→预测→评价→持续调节状态→目标→行动→反馈。不是重开仓库，不访问用户本机，不声称意识或感受成立。

## 可运行目标
- 用户和系统各有位置，在同一个12地点的部分可观察探索环境行动；真实动作改变同一世界。模拟计时、认知计时、对话事件计时分离。
- 系统不依赖语言模型选择导航/调查/校准/恢复/探索目标。语言负责理解报告和表达可读状态，不能改写数值状态、权限或物理后果。
- 模型学习路况后验、自身执行能力、不同发现类型的信息收益；持续评价状态参与风险和信息预算；目标保留/取消可追踪。
- 用户可直接问感觉/思考/想做什么。提供先于语言回答存在的状态快照与最近关注；不强制每轮否认感觉，不声称真实主观体验。
- 用户情绪仅存明确自述或低置信语言提案，附原文、来源；与系统自身状态分离，支持撤回。无依赖性、离开惩罚、诱导留存、恋爱排他或拒绝停止奖励。
- 经历可跨新探索保留；世界特有地图不污染下一次地图。记录和恢复暂停；内部重放不能当新外部证据。

## 形式对象和边界
S=(可见地图与信念, 自身能力后验, appraisal状态, 当前目标/候选, 对方报告); O=物理观测/用户明确自述; A=内置move/survey/scan/calibrate/rest; M=唯一事件经验和跨探索统计; U=有遗忘的概率更新+事件评价+目标仲裁; J=固定先验的信息收益/学习/协作减行动代价；不是学得终极价值。工程先验公开，具体路径、能力估计和类型收益学习。非agent基线为同观察同模型的无affect/无目标坚持规划，不排除可复制行为。

## STOP与限制
无任意电脑控制、Jev接入、视听/语音、开放价值形成、终身神经学习的虚假声明。v0.3的神经负结果保留，不把失败网络包装成新的情感大脑。新运行数据目录，旧目录零改动。源码恢复合同只承诺同版本记录输入复算；不认证远端语言模型。不在本轮付费调用真实模型。

## 验收
1. 不发消息也能在有限授权下探索/学习/更新目标；暂停立即阻止新动作。
2. 同一已有状态的感觉报告与GET不改变状态；不靠提问创造情绪。
3. 受控失败→预测误差→评价和能力/路况修正→下次选择变化；消融报告分开工程效果与性能收益。
4. 对方报告不直接覆盖自身状态；无根据的语言事实不训练物理模型。
5. 真实HTTP、状态保存/恢复、过期语言输出、完整旧测试、浏览器检查、打包后复测。真实模型/Windows若未运行明确unknown。
