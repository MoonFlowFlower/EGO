# v0.4 自查记录

没有可用的独立reviewer或用户仓库访问；本记录不称独立审计。

本轮目标是保留基础设施、把任务助手主入口替换为共同经历驱动的持久状态/预测/目标/行为。核查范围：真实世界事件→学习/评价→实际选择→执行；报告在自然表达前固定；没有用户输入也能在有限授权下行动；状态保存/恢复与停止；来源和权限隔离。

重点风险及处理：
- 神经网络名称冒充机制：旧网络保留但不在新默认路径；文档明确新控制器采用有界概率学习与工程评价。
- 只计数不影响决策：同历史self/affect干预比较实际动作，留存改变与不改变的结果。
- 模型偷读答案：内核持有隐藏World；context仅共享可观察状态和来源化历史；测试排除隐藏键。
- 情感标签后生成：查询不会改评价值；状态快照先于表达，但来源解释可能出错，须允许撤回。
- 感情话术造假：默认本地状态报告明确不是语言模型；协议要求表达现有状态；真实语言语义未实测，不承诺保证忠实。
- 非法越权与迟到动作：仅内置有限动作；pause/新输入/世界修改使输出失效；无隐式付费重试。
- 旧证据误用：旧版本证据标旧目录，新包单独清单、实例、完整测试与外部重新解压记录。
- 比较收益缺失：保留完整候选探索效率落后的负结果，停止优越性声明；不因此取消所有功能研究。

未解决：评价规则可学习性、社会语义可靠性、长期模型容量/遗忘、模型偏差与复杂路线规划、真实用户互动体验、外部操作与语音。没有通过新增字段把这些标成已解决。
