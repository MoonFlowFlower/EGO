# Shared Field v0.5 · 继续同一段共同经历

这版沿着“共同经历 → 学习与持续状态 → 自己的倾向 → 交流与行动”的方向继续，不改回任务工作台。重点是同行约定、言行对应、对方行动预测与经历脉络。它是有界机制实验，不是已证明具有主观体验的电子生命。

## Windows 启动
完全解压到一个新文件夹，进入 `SharedField`，双击 `START_WINDOWS.bat`。需要已有 Python 3.10+，无第三方运行库依赖，不自动安装、下载或调用模型。**不要覆盖 v0.4 目录。**

```bash
python run.py shared
```
默认 `http://127.0.0.1:8773`。端口占用时：`START_WINDOWS.bat --port 8774`，或 `python run.py shared --port 8774`。命令行窗口保持运行；Ctrl+C 退出。Linux/macOS 用 `sh START_LINUX_MAC.sh`。

## 接着刚才的探索，不必再从营地重来
右上角 **接着旧探索**，选择原来的 `SharedField_v04_checkpoint.json`，或已转换的 v0.5 检查点。已有当前会话时会请求确认并归档，然后再导入；验证失败不替换当前状态。初始导入后暂停，不自动重发旧请求。

导入保留旧对话、位置、体力、已学物理估计和原始事件。新增加的对方选择预测器从零学习；过去的物理经历只重建有来源的记忆，不伪装成新预测器之前已经训练过。导出时尚未完成的回答不会补造；界面提示后，可重新问一次。

本轮发现 v0.4 浏览器把 `0.0` 写成 `0`，原严格读取器会失败。新迁移器使用包内冻结的 v0.4 代码重新计算，要求原事件哈希、状态哈希、链头全部匹配，只兼容有限数值的整数/浮点表示及原有12位小数合同；布尔值不当成数字。不是关掉哈希检查。v0.5 使用便携数值规范，导出不再主动解析再序列化。

```bash
python run.py shared-verify "SharedField_v04_checkpoint.json"
python run.py shared-import "SharedField_v04_checkpoint.json" --data-dir "continued_data"
python run.py shared --data-dir "continued_data"
```
CLI 导入拒绝覆盖非空会话。v0.5 数据仍与源码绑定，请保留数据与产生它的版本。旧 v0.2/v0.3 不是当前内核的等价检查点。

## 一起走，而不是各走各的
- **一起走**：采纳持续的共同活动约定；她可以先调查身边的地点，领先后等待，观察到分离或受阻时优先尝试会合。你仍控制自己的移动。
- **等我一下**：内部等待，不重复执行休整、不消耗物理步骤或模型调用。
- **我准备好了**：恢复等候前的活动模式。没有剩余授权时，需要再次允许探索。
- **各自探索**：撤销共同移动约束；各自行动仍可交流发现。

这些按钮不授予行动次数。使用“让她探索”的8步、32步或到本图结束（最多600步）授权。暂停清除剩余授权；等待保留剩余授权。语言模式中，也可以直接说“一起走”“在这里等我”“各自探索”；这是可错的语义抽取，不是确定性语音指令。重要控制可使用按钮。

## 直接问感觉、想法与意愿
可以直接问“刚才发生的事对你有什么影响？”“你现在想做什么？”“为什么改变主意了？”

回答读取先于表达存在的状态，而非回答之后再生成一份解释。现有来源记忆会把失败、检查、到达和修订联系起来；不必每次把候选分数表念出来。无新经历时允许保持原状态。

每个语言回答有**当前意图回执**：待执行、已实际尝试、因新观测修改，或较早快照。表达阶段明确分开已选动作与备选；有限措辞检查会校正已识别的“说先校准、实际却走路”等冲突，并显示校正标记。原始模型输出仍留在导出事件中。**它不是通用语义验证器**，不能保证任意措辞都正确。

你在语言返回期间操作地图，不再直接丢弃已付费的回答；较早快照会标明时间差，也不会回滚当前决定。会合邀请和同行/等待约定也不会擦掉当前问题；新问题、暂停、换探索等明确改变对话/控制的操作仍可取消旧响应；请求已经发出可能计费，不自动重试。

## 对方模型与记忆这次学了什么
从真实的用户移动选择，在线更新4类发现的 softmax 选择预测，并记录更新前预测。重复撞同一段路不当成多个独立偏好样本。只有在已采纳的同行状态中，该预测才会小幅影响目的地排序。显式约定、能力与风险仍参与选择。

这只是受路线可达性、你的测试方式等影响的**行为预测**，不等于识别人类情感或真正偏好。简单频次统计也能解释当前合成例子。物理模型仍使用有界概率学习；没有把旧小神经网络改名成情感大脑。

“留下来的共同经历”显示真实事件来源；移动失败形成可检查的问题，校准提供证据，目标到达关闭对应问题。一个地点的成功不会删除另一条失败路线的问题。回看不产生新证据，不是神经巩固。

## 模型连接与费用
默认本地状态报告不调用模型，也不是自然语言理解。右上角模型连接，填已有兼容 Chat Completions 服务的基础地址、模型ID、密钥；已有本地兼容服务也可用。基础地址不含 `/chat/completions`。远程 HTTPS 需明确同意发送所选上下文，本地可 loopback HTTP。

通常一轮对话2次请求：解释 → 状态快照 → 表达。“探索中讲述”是可选的实际事件后额外请求，不是空闲定时搭话。默认生命周期48次请求上限，可调整；是数量预算，不是金额封顶。导入保留已使用计数。密钥只在进程内，重启后重新填写；不会迁移密钥。不要在聊天正文里输入秘密。

两阶段协议自检会确认后调用最多2次；只检验协议。手动交换逐阶段复制请求和JSON，无人值守语言运行需要你自己的模型服务。**本次新版没有调用真实云模型或本地大模型；用户提供的旧版真实输出用于定位缺陷，新版语义效果仍需实测。**

## 保存、权限与测试
每次提交自动原子保存到 `user_data/shared/session.json`，重启恢复暂停。“新探索，保留经历”换地图但保留学习与历史；“新个体”归档后清空。导出含对话和用于复算的隐藏实验状态，公开前自行检查；隐藏真值不会进入模型上下文。

```bash
python run.py test
python tools/shared_benchmark.py --seeds 8 --steps 80
```
