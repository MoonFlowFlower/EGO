# 本版机制边界

## 已实现，不等于有效性已证明
S：当前状态、工作任务、等待条件、已处理观测。
O：用户原文、真实本地工具结果、显式验收反馈。
A：本地草稿、一次数值动作、规划、记录与提问；没有外部操作。
M：原始事件、有来源的语义表达、草稿、前瞻任务和反馈。
W：原数值实验已知结构族中的 Bayesian model；语言模型没有另行训练一个开放世界模型。
G：模型提出的有限目标、版本、持久性、取消/暂停/等待，工程排序。
V：有限请求、计算步数、资源、未解决任务；没有依恋/害怕关闭奖励。
U：数值后验更新、显式任务结果的 Beta 统计、原文及工作上下文变化。
pi：语言提案 + 合同检查 + 有界调度 + 数值控制器，不是 LLM 直接拥有机器权限。

任务工作方法 outline/compare/direct 是工程给定的候选，其成功率估计由你报告的验收更新。每份草稿仅计一次，重复赞同不增加评分。它没有排除简单 bandit、长上下文 LLM 或状态机等解释。

异常路由阈值 surprise > .8 nats 且 observation-conditioned KL > .08 bits 是公开工程先验。不是学出的潜在动机；不是每个真实异常都一定满足，也不是满足就一定值得更深研究。数字模型中的噪声零信息与环境演化要分开。

## 四个不同结论
工程接线通过：存在入口、显式开启、实际触发、状态转移及下游行为测试。
机制因果证据：只覆盖特定干预测试，不自动推广到语言心理能力。
比基线有收益：本版尚未做真实模型质量/费用比较。
EGO 主链生效：未接入，不能由本地包推断。

## STOP
模型只产生漂亮解释但不能改善产出；复杂状态的收益被更简单方案抹平；依靠每种现实情景加专用规则才能工作；不断超预算或丢失约束。以上都要求缩小、替换或停止当前路线，不用提高人格表现遮盖。
