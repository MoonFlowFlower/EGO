# SwitchLab Studio v0.2 — bounded language/persistent loop

User-authorized scope: extend the existing package into a locally runnable language-connected form, rather than stopping after an uninformative simple-world comparison. No EGO/ITL repository or live mainline access is involved.

The old numerical experiment remains intact. A persistent Studio controller links arbitrary Chinese conversation to grounded memory proposals, durable goals, bounded tool plans, actual local draft artifacts and simulation observations, and explicit outcome feedback. LLM-generated text is NOT itself observed evidence or execution proof. The general-language planner is an engineered proposal mechanism, NOT a learned motivational system.

Objects: S=current working state, O=user/tool events, A=allowed internal sandbox tools, M=raw events plus source-linked claims and consolidated outcome statistics, G=versioned persistent plans, V=call/work budgets and unresolved commitments, W=existing Bayesian toy model plus task-strategy outcome estimates, U=Bayesian updates and feedback-count updates, pi=goal arbitration + language proposal + deterministic execution gate. System/environment boundary is the explicit tool interface. No shell, arbitrary file paths, browsing, messaging or external purchases.

Routes considered: (1) language-only narration of SwitchLab (rejected as insufficient); (2) unrestricted computer agent (rejected as unnecessary and unauthorized); (3) bounded semantic workbench plus existing numerical world (selected).

One model call handles conversation interpretation and proposals. Real tool work is scheduled separately; draft generation is another call, then a real immutable local artifact is committed. Future prompts receive actual outcomes. Steps not requiring language execute without an API call. Goals awaiting feedback do not keep generating text. Runtime can continue queued local work without new user messages, but never makes goals solely because a timer fired. Pause invalidates in-flight results; resuming requires an explicit control. Finite work and call quotas, no automatic paid retry.

Default no credentials/no remote calls. OpenAI-compatible chat-completions HTTP supports OpenRouter/local Ollama/other configured providers. Keys exist in process memory only; requests do not follow redirects. Manual copy-paste model exchange is a real alternate transport, not a scripted fake model. Production has no canned intelligent reply fallback. Synthetic completions exist only in tests and labelled demo evidence.

Validation: original regression suite; protocol and scope rejection; real language-output-to-tool-state-to-future-context wiring using explicitly synthetic provider responses; actual local HTTP adapter tests; goal pause/cancel/revise races; atomic persistence/restart; no hidden state to language; feedback cannot change lab beliefs; source-bound deterministic replay treating recorded model outputs as exogenous inputs; desktop/mobile browser flows; fresh extraction verification. Real remote-model behavior is unknown without credentials and an actual call; no claim will upgrade contract tests into semantic language evaluation.
