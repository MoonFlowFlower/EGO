# 机制、形式对象与声明边界

## 当前层与实际接线

层：engineering implementation + 有限模型族 online latent-state adaptation。

本地 entrypoint：`run.py` → `Session.step()` → `Agent.decide(public_observation)` →
`World.step(action)` → `Agent.learn(real_transition)` → 后续决策读取更新后模型。
需要用户主动启动。只有 13 个明确列出的 toy 动作，没有 shell、真实文件编辑、浏览器操作、
邮件、支付等外部权限。网页绑定 127.0.0.1，并检查 Host、Origin 和会话 token。

这是独立实验包，没有接入用户 EGO/ITL 主链。用户仓库与其当前运行状态未被读取，不能替它们报 PASS。

## 形式对象

- X：环境的两个源模式位与工具健康位，加公开资源、承诺与延迟成本。
- O：时间、能量、冷却、承诺进度/截止点、待发生成本、已完成/错过计数。
- A：e0/e1/c0/c1、手工采集、交付、两个环境 probe、自身 calibration、repair、wait、noise。
- S：8 状态后验、当前目标、缓存的内部规划结果、学习统计。
- M：真实的 action/outcome/observation 经验序列。
- W：固定响应族中的当前后验预测模型；不接收环境实例、真实 seed 或隐藏状态。
- G：从后果候选选择的目标实例，带来源、目标值、采纳时刻、预算与前序状态。
- V：可见能量/冷却及其偏好区间；不是拟人化饥饿或关闭恐惧。
- U：Bayesian likelihood conditioning + 指定漂移预测；或经验图缓存的更新规则。
- π：有预算的粒子 rollout MPC；保留两步 expectimax 作为原始对照。

核心更新：b'(z) ∝ p(outcome | action,z) b(z)，然后预测下一步隐藏状态。
动作比较：模型内折扣环境回报 + 截断后的资源/进度价值 − 显式目标切换成本。
采用 8 粒子、10 步想象，固定续行启发式，实际每步重新规划。
这是一种近似策略评价，不是精确 Bayes-optimal，也不声称全局最优。

## 工程先验与学习证据分开

| 对象 | 工程先验 | 真实随经历改变 | 没有证明 |
|---|---|---|---|
| 世界模型 | 8 状态类别、似然、漂移先验、公开物理 | 后验、下一行动结果概率 | 学出新的模型类别或未知物理公式 |
| self-model | 工具健康这个因素及观测模型 | 工具健康后验影响预测/行动 | 主体、自我意识；完整能力自我模型 |
| 目标形成 | 有限结果模式、目标价值和切换成本 | 对具体结果/动作的比较与采纳 | 目标模式或终极价值完全学得 |
| 规划 | 固定预算、续行启发式、粒子采样 | 随信念与经历选择不同未来和行动 | 完整通用推理或最优控制 |
| episodic memory | 保存接口和时间顺序 | 真实经历持续追加 | 仅靠存在日志就获得记忆机制证据 |
| semantic state | 贝叶斯统计结构 | 历史汇总为后验 | 任意抽象概念形成 |
| replay | 重算同一条已发生经历 | 可恢复相同后验 | 新独立证据、神经巩固或额外收益 |
| internal work | 可缓存的规划调用 | 无新观测时更新工作区，随后被读取 | 自发无限思考或 Global Workspace Theory 成立 |
| value | 资源、交付、成本函数 | 状态变化导致不同权衡 | 内部价值自主起源 |
| social model | 无 | 无 | 未实现，不用情绪措辞或空类假装实现 |

续行策略中存在资源阈值和任务优先级，这是已披露的工程先验。
候选、直接 Bayes、知情参考共用；反应式 Bayes baseline 直接使用这套续行策略。
因此候选不能把这一启发式的能力归因于额外“自己的想法”。

## 关键消融的狭义含义

- freeze_learning：固定后验，不吸收新证据；不等于冻结所有可能学习机制。
- memory_reset：每步重置统计状态，虽然记录仍在；不是把日志文件删除的仪式。
- no_self：强制认为工具健康，相当于一个故意错误/删减的因素模型；不是容量匹配的最终反证。
- no_planning：用单步评价替换长时域 rollout。
- no_viability：移除终端资源势函数；环境仍有资源后果，续行策略仍有任务必要的资源关注。
  因此不能把这个消融命名为“去除了全部动机”。
- no_goal_commitment：去掉显式目标的切换影响，保留同一最终目标和规划器。
- no_replay：不作周期性精确重算。预期动作完全一致、计算更少。

## 假自主和泄漏检查

同一空闲时长、不同资源需求导致不同动作；同一当前观测、不同证据历史能导致选不同资源源。
纯噪声 likelihood 与隐藏状态无关，不能通过重放积累信息。
人为故障只改变环境，不直接改变候选 belief。
`oracle_reference` 是唯一允许接收隐藏真值的配置；普通候选调用对应接口会拒绝。

环境与候选物理预测是两份独立实现并作对照测试，但二者共享公开响应族假设。
这不是候选独立发现了世界法则的证明，也不是结构 OOD 泛化证据。
压力情境只改变成功率/诊断准确率，不能写成“未知因果结构已经通过”。

## 下一步最小闭环与 STOP

用户首先检查启动、步进、干预后更新、保存恢复和同种子基线比较。
若用户环境运行失败，先定位可复现的接线/兼容问题，不调模型参数掩盖。
如果规则或反应式 Bayes 持续更优，停止增加目标模块，采用更简单控制器；保留本包作为仪器。
若要研究真正的巩固或未知结构，必须设计一个精确充分统计量不已解决的问题，而不是调本版
replay 计分；需要新的有界问题与公平的历史/元学习基线，不自动恢复任何暂停路线。

最高声明不超过本源码与 trace/replay 合同下的有界离线功能观测。
