# Shared Field v0.5 — 同一段经历中的言行、共同目标与连续性

继续执行用户已确认的 Shared Field 方向；在隔离副本开发，不涉及真实电脑权限。不是开启任务助手/人格prompt/自动恋爱脚本新路线。

## 由本次实际测试定位的问题
- 108条事件，26个物理步骤。已保存的言语两次宣布扫描/校准，而已选及下一实际动作仍为move。问题在表达候选与已选动作未分离，不是语气不够亲密。
- 玩家行动取消正在付费返回的对话，产生未答消息；新物理观测不应等同于取消用户话题。
- 玩家rest误完成agent的rest目标，虽agent体力不变；目标所有者缺失。
- 会合仅有一次邀请，无持续共同探索约束；玩家受阻时没有未决共同问题与后续修订。
- 导出经浏览器JSON stringify把0.0变0，原比较器认为不同；本次原样strict replay确实失败E5。不可把这个失败删掉；按原代码逐事件重算、原哈希一致且数值类型规范化单独验证迁移。

## 实施范围
1. 便携数值合同与v04迁移：只放宽有限数字的整数/浮点表示（保留bool区别及原12位浮点合同），不放宽结果、哈希和来源。冻结原代码验证旧轨迹；原始材料不进入公共示例。保留旧状态历史/地图/已学量，新事件承认schema切换并清除未完成远端请求，暂停恢复。
2. 单一已选意图：实际selected action与备选严格区分，生成回答带计划绑定。已选计划无需重新猜；表达发生前有可读动作承诺，执行后有结果回执，因新证据修改有原因。窄范围语言行动冲突守卫可修正已识别的相矛盾句，但不称全面语义验证，不偷偷重试模型。
3. 连续共同活动：自行探索/一起走/等我三种有限共享承诺，单次会合仍保留。共同模式对分离、体力和路况的预测进入候选，等待是非物理控制状态，不能靠重复rest耗完授权。被观察的受阻形成待协商问题，不从失败断言用户悲伤；候选建议不自动提升权限。恢复和取消有明确入口。
4. 经历记忆与内部复核：自动形成带实际来源的失败-调查-修正脉络与共同发现回忆，保留过去/现在区别，减少永远“尚未校准”的陈述。反思处理尚未整合的经历，产生待解决问题而非新外部证据。问题影响协作计划和表达，并可消融。
5. 语言可理解直接的同行/等待/偏好反馈但不能写物理真值、凭空创建感觉或设置权限。没有新体验时允许普通聊天，不反复报分数/架构声明；显式询问体验真实性仍承认未知。

S=(物理信念,自身能力,持续评价,共同承诺,未决问题,工作记忆);
O=真实动作/用户原文及其可错解释; A=既有环境动作+内部等待/回看; M=唯一经历和来源化概括;
U=原概率更新+归因正确的目标终止+有限问题/承诺转移;
J=既有信息收益与成本+在用户采纳的共同活动中维持协作可行性。协议与权重是工程先验，不声称学得价值起源。

## 验收与STOP
- 用本次实际轨迹找缺陷，用泛化合成事件做回归，禁止针对用户具体原话硬编码答案。
- 所有新增路径都从UI/HTTP主入口启用；暂停、读GET不学习、坏动作原子回滚、记录输入复算。
- 相同历史移除协作记忆/共同约束可改变对应行为；简单双人规则也可复制，不能升级主体性。
- 旧负基准保留，跑相同效用的新比较，不改评分翻绿。缺失强语言/元学习基线明确未测。
- 不增加Jev、云服务、训练收费、系统键鼠权限。真实语言效果需用户模型实测。Linux本地测，不宣称Windows或独立审计。
