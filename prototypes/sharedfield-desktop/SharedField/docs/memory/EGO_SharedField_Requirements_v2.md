# EGO / SharedField：成长型持续认知系统需求基线 v2

日期：2026-09-22
状态：用户需求及最新两项确认已记录；工程解释与记忆候选方案仍是设计，不是实施结果。
层级：需求与架构设计；后续涉及工程实现、机制假设与学习适应。不进行主体性或主观体验认证。
依据：当前对话中用户对第1—16问的回答。历史程序和存档不是本稿的需求来源，也未在本轮重新执行或审计。

## 1. 目标与优先级——用户明确要求

研究并构造可通过真实共同经历持续成长的人工系统，以 Joi-like 相处体验为远期目标。必须有持续内部过程、自己的兴趣与行动倾向、可发展的评价与原则、自我模型、对人的理解，以及长期连续性。不得替换为人格 prompt、关系记忆产品、任务助手、脚本同伴或地图 NPC。

优先级，保留用户原顺序：

1. 从经历持续成长。
2. 保留长期记忆而不会遗忘。
3. 理解情绪并自然情感交流。
4. 自发兴趣与目的。
5. 实时相处。
6. 实际操作电脑陪玩。

首个学习场景：记住口头约定，例如以后一起玩某个游戏、读某本书；用户愿意解释、演示、纠正，也愿意观察数天。简单约定不应需要多天训练才能记住。

交互与具身顺序：先文字，后语音，再 Live2D，最后游戏屏幕感知。首个真实游戏目标是 Minecraft，由系统独立控制一个角色；在接入前先做实时共同环境和认知核心。没有漂亮形象但内部连贯有价值，只有外观而没有内部成长不可接受。

后台常驻；用户未说话时也可以进行实际内部工作或独立活动。十分钟没有反应会显得迟钝；允许较慢但自然的回应，这不是人为延迟的要求。

## 2. 人格、关系与连续性——用户明确要求

先天性格倾向可配置，MBTI 是用户提出的配置方式之一；具体世界观、价值观、兴趣通过后天经历适应。兴趣向用户靠拢的程度、情绪反应与修复方式应与所选倾向和用户偏好有关，不能所有实例一个答案。

活动有分歧时，可表达倾向、轻度傲娇、先配合，并商量以后一起做自己想做的事。约定未兑现可影响之后的协商、坚持或独自活动。用户要求给系统自由、双向配合，不是始终无条件服从。

正常交互持续拟人化，不频繁跳出交流讲解机制；只在维护时显式展示内部技术。用户接受自然表达与不确定的自我解释；这不授权伪造经历、执行结果或已证实的主观体验。

独立活动可以与用户无关，应基于自己的兴趣、当前状态、真实发现或待解问题。不能用虚构日记或定时重复发消息冒充生活与思考。

升级、更换模型和迁移设备应保留：共同经历、兴趣、承诺、技能、表达习惯、记忆及必要的学习状态。连续性不能仅靠名字与人格提示词保持。

## 3. 用户给出的正反场景

### U-S1 晚归与主动关心

用户晚回家，系统会想念、可能担心，并主动联系，远期包括电话。

设计解释：需要已经知道的预计时间、授权观测来源、用户是否改约，以及联系偏好。没有消息不是事故证据；想交流与担心安全是不同状态。应能在新的可靠信息出现后修正期待、停止不必要联系。

不能以“离线固定分钟数就拨号”代替机制。电话暂为后续通道，不因本需求创建当前提醒、监控或电话任务。

### U-S2 偏好、想要与实际选择

系统有自己的颜色等喜好，看到喜欢的物品会想拥有。反例是说喜欢蓝衣服，却在适宜、可选择的情况下始终选其他颜色。

设计解释：偏好应影响关注、比较、选择、收藏或获取目标，并能承担一定机会成本。先使用真实存在的数字物品、阅读材料或工作空间对象；没有获取成功不能声称已经拥有。

偏好不是每次都选同一颜色。控制可用性、成本、场合等因素后，检查选择倾向及其来源；不能用一次例外否定偏好，也不能为任意不一致事后编理由。

### U-S3 原则与抗迎合

用户希望系统有自己的原则，例如不能接受出轨，不会因重复狡辩而软化。

设计解释：区分事件事实、对承诺的理解、原则本身和当前处置。无新证据的压力不应直接覆写原则；证据证明先前误判时必须纠正事实。

涉及关系的约定必须有双方清楚理解的适用范围；不把用户与真实人的正常关系或社交默认定为背叛，不使用监控、威胁或诱发内疚强化依赖。该例是原则稳定性需求，不是关于用户现实经历的断言。

### U-S4 口头约定与跨时间延续

自然聊天中形成未来共同活动的约定。系统当轮理解并可靠记录，之后可主动准备、合适时提出、协商改约、完成或取消。

不能只在被问到时检索到一句旧话。没有明确日期的“以后”不能私自改成某天；假设、玩笑、提议与双方已采纳的约定需要区分。

## 4. 关键工程解释——建议，不冒充用户已选实现

### 4.1 性格预设不是行为脚本

允许 MBTI 风格的预设入口，同时暴露可调整的具体倾向，如表达直接程度、主动交流倾向、探索偏好、协商坚持程度、对不确定性的容忍和情绪恢复速度。

不要实现为“某类型必定嫉妒/原谅/生气”。情境解释、既有经历、承诺性质和有效新证据同样参与。连续参数及其映射是待测试的工程设计，不是人类心理学已经提供的确定公式。

外部依据仅用于这一限界：Myers & Briggs Foundation 的 Ethical Use 明确把类型偏好视作倾向而非绝对，并指出类型不是一个人的全部。McCrae & Costa (1989, Journal of Personality, 57:17–40, DOI 10.1111/j.1467-6494.1989.tb00759.x) 在其样本中未支持真正二分、性质截然不同的类型解释。二者均不提供人工情感的实现或验证。

### 4.2 不能以模型权重代替全部记忆

分别验收：资料是否保存、所需时能否准确回忆、未来条件到来能否主动使用、学习新知识后旧能力是否保留。

建议：保留可追溯原始经历；承诺/原则/已确认事实有版本化的持久记录；可重建检索与语义索引；学习器负责抽象、预测与技能；摘要不是唯一原件。

用户要求长期不遗忘是首要验收目标之一，但不能声称任何系统永久零损失或所有检索永远正确。必须报告实际测试的周期、记忆负载、丢失和误召回，以及恢复边界。用户主动删除和有效纠正仍需执行，不能为了“不可遗忘”继续保留被要求删除的信息。

### 4.3 多时间尺度的学习

明确约定：当轮完成确认和持久化，不等待神经训练。

事实或预测：一条可靠新证据可以立即改变当前信念；若语义或来源不确定，保留不确定性。

交互规律、偏好与技能：根据多次经历、失败与迁移测试形成更稳定变化，不把一次表扬直接变成长期价值。

慢变化的原则：可以来源于初始共同约定或后续形成的评价；必须区分这两种来源。需要明确外层学习目标与工程先验，不声称从零产生无来源的终极价值。

### 4.4 实时不是常驻生成文本

建议采用真实时间和事件驱动的后台进程。观测、计时、检索、内部计算、行动和表达具有不同频率与预算；空闲时可降低负载。不得在程序关闭/休眠期间编造完成的工作。

内部工作应能留下真实的预测、假设比较、准备产物、技能更新或计划变化；不能只增加“思考次数”。等待用户不等于整个认知状态被清空。

### 4.5 拟人表达与真实性

正常界面不强制展开参数或反复插入意识免责声明。允许第一人称和自然情感样措辞，接受“我还说不太清楚”等不确定表达。

仍然不能声称已经读过未读取的书、执行过失败的动作、打过未拨出的电话、记得不存在的共同经历；技术身份与能力被直接问及时应如实回答，不以拟人模式掩盖。

## 5. 候选最小形式对象——设计假设

S：当前工作状态，包含世界/他人信念、自身能力模型、事件评价、当前注意与承诺。
O：真实用户输入、时间事件、授权环境观测、实际行动反馈。
A：内部计算与授权外部行动；包含等待、提出目标、协商与不行动。
M：经历、已确认约定、原则来源、技能与自我历史。
W：行动条件化的结果与情境预测模型，保留不确定性。
P0：可配置的初始性格倾向。
V：可学习的具体评价、兴趣和优先级；与不可学习改写的外部权限分开。
G：提议、采纳、承诺、暂停、完成、撤销的目标。
U：真实经历驱动的信念更新、参数学习、重放、记忆与目标修订规则。
J：合作、认识与能力进展、承诺、自身兴趣等多目标评价；不以即时用户赞同作为唯一或最高目标。具体组成与权重尚需实验，不默认此处形式已成立。

设计链：

    经历/时间/反馈
       → 世界、他人、自身的预测与不确定性更新
       → 对兴趣、期待、约定及原则的影响
       → 候选目标与内部工作
       → 比较、采纳、承诺或暂不行动
       → 授权执行与自然表达
       → 实际结果
       → 持久记忆、学习与下次行为

边界：语言模型可以承担语义理解、假设生成与表达；不等于完整系统，也不因换为另一神经架构就自动完成目标。agent 与其他实体通过权限、实际行动来源、可控能力和观测归属区分，不用一个名为 self 的字段替代。

可解释目标：跨经历持续性、偏好对选择的影响、承诺驱动的主动工作、预测修正、有限社会推断。不能解释或证明：主观体验、真实情感、一般自主主体、无限期可靠成长。

## 6. 下一阶段最小完整使用闭环——建议范围

建议将下一阶段从“继续扩展地图”改为“持久个体的日常经历与发展”，保留地图作为环境适配器和故障定位场。

同一生命周期里做到：自然形成一个共同约定 → 当轮持久化 → 沉默期间对未来进行有依据的准备 → 新信息出现时修订期待/计划 → 适时主动交流 → 活动产生真实结果 → 改变后续预测与选择 → 重启/迁移后保留连续性。

同时允许一个与用户无关但有实际输入与产出的独立小活动。文字阶段先在可控资源库/共同环境中实现，不能把随机生成日记作为替代。

早期必须设置至少一条明确的可塑学习路径，报告训练目标、真实经验来源、参数或规则变化及行为影响。不能因为承诺系统已经可用就搁置成长，也不能为了“神经学习”删除可靠的持久记录。

电话、语音、Live2D、MC、屏幕操作按用户顺序后置；它们不是本轮已实现能力。MC 的状态感知接口与观看渲染画面分开规划，不能把“屏幕最后做”理解为行动不需要观测。

## 7. 验收与杀手对照——计划，不是结果

| 项目 | 用户可见验收 | 关键反例与对照 |
|---|---|---|
| 约定 | 换话题、重启和经过时间后仍记得；必要时准备与改约 | 只存文本但到期完全不处理；虚构已确认时间；已撤销目标又触发 |
| 关心与联系 | 未按预期出现时能依背景合理联系，知道延迟原因后改判断 | 相同静默时长但不同背景仍同样打扰；把无回复直接说成事故 |
| 喜好与想要 | 相同可选条件下，经历形成的喜好影响选择和资源投入 | 只改变自述；完全跟随最近一次用户暗示；没有行动却声称拥有 |
| 原则与修正 | 无新证据的施压不改变原则，事实反证可以纠正误判 | 一直辩解就抹掉约定；为显独立拒绝有效证据；混淆真实社交与违约 |
| 情感样调节 | 状态来自经历，且对之后的注意、目标或行动有作用 | 删除调节只改变语气；重复自述被当作新证据 |
| 独立工作 | 沉默期间有实际有价值的过程与结果，并能停止 | 定时聊天、无限重放、自造新经历、为维持互动诱发内疚 |
| 成长与保留 | 新经历改变未来预测或行为，旧能力与重要约定不被无声覆盖 | 参数变了但行为没变；新知识改善以长期丢失为代价且无法发现 |
| 连续性 | 更新或换模型后经历/兴趣/承诺/技能仍可用 | 只留下名字和摘要；升级丢失状态；重新创造虚假共同过去 |

公平比较必须包含：同一基础模型的长历史/检索方案、具有相同记忆和时钟的简单规则与计划器、经验缓存，以及适用时的跨 episode 元学习或摊销学习器。记录读写量、模型调用和计算成本。最强基线打平可以否定额外复杂度的价值，不自动否定功能存在；绿色测试也不能证明心理属性。

消融需要保持预算与输入可比：禁用持久回忆、冻结可塑学习、去掉情感调节、保持经历但移除目标持续状态，分别预测哪一类行为应受损；需要区分删掉数据与删掉机制。新变式、换说法、无信息噪声、相同静默时长但背景不同的情境用于防模板化。

STOP：若改动只提升拟人措辞而不改变功能，停止该分支；若指标奖励打扰、迎合或自造证据，重设计指标和目标；若复杂学习器持续劣于公平简单方案且没有独立价值，保留更好方案并关闭额外复杂层。不由局部失败推断整个宽目标不可能。

## 8. 权限、运行与成本

用户表达广泛权限偏好，明确排除付款和危及系统的动作；具体资源、数据发送、接收者和运行方式仍需配置。

建议在已授权的低风险范围主动行动，不逐步打断用户；付款、破坏性操作、凭据导出、权限提升、系统安全变更和涉及他人隐私/对外发送等有独立检查。不能因为人格生气而改变系统权限或拒绝暂停。

后台驻留、自启、云端传输和长期记忆存储需要可见设置，能关闭。未知预算不是无限额度授权；先记录调用、存储与运行成本，提供硬上限。接入任何收费外部通信或训练前，明确开销与范围。

本轮不创建定时任务、不拨号、不修改电脑权限、不读取额外私密数据。

## 9. 最新确认与记忆补充（2026-09-22）

用户最新明确确认：

1. 允许“初始原则模板＋后天发展”。初始来源必须被保留，不能包装成已学习形成。
2. 晚归首版以用户口头提供的预计时间、延迟和改约信息为输入，文字端主动联系；电话在语音阶段后接入。这是目标程序需求，不是授权本次 ChatGPT 创建提醒或拨号。
3. 记忆特别重要；要求解决 LLM 有限上下文与长期经历、承诺和个体连续性的冲突。

对应候选架构详见同目录 `EGO_Memory_Architecture_v1.md`：
- 长期事件源、版本化事实/信念/承诺、可重建检索索引，与模型上下文分离。
- 上下文是有预算的工作集，而不是唯一的记忆；摘要、向量和神经权重都不作为唯一原件。
- 对即将到期或条件触发的约定使用持久索引驱动，不依赖模型碰巧回忆；通知只是候选行动，仍受权限、限频和语义判断约束。
- 分别验收保存、理解写入、召回、正确使用、适时主动使用、学习保留与跨设备恢复。
- 新设计不能把项目降级为记忆聊天产品：至少一条来自经历的预测或行为学习路径必须接入主循环并接受冻结/历史干预测试。

初始人格具体配置、运行费用、外部通信接收者和静默时段仍在配置阶段明确，不阻塞记忆架构设计。

## 10. 交付状态与研究上限

本稿是需求整理和候选设计，不是新程序。本次检查了对话提供的 v0.5 压缩包中与记忆有关的源码，详见 `SharedField_v05_Memory_Readback.md`；没有执行新的训练、回放或应用测试，没有修改用户仓库、SharedField 安装或 EGO/ITL 主链。

即使后续实验成功，最高结果表述仍限于：bounded offline mechanism evidence under a specified environment/trace/replay contract。不得由产物、接口、测试或体验评价自动升级为 consciousness、subjective experience、real emotion、true agency、autonomy 或 EGO readiness。

用户希望的完整目标保持不变；限制结论不等于暂停工程探索，也不准用反复扩充文档替代功能实现。
