## 关键调用链
message先保存 → interpret请求 → exact quote/namespace/version检查 → 单事务claims/commitments/availability/feedback/world_request → durable receipt → 带当前有效版本的express请求 → 输出保存。

后台：本地真实时钟查due → 约定revision/忙碌状态/后验结果 → 先等待或prepared候选 → 模型决定wait/contact → 输出前再检查revision → 本地消息回执 → 明确实际反馈 → 下次候选。时钟和阈值是工程先验，不是自主性证据。

检索本身不更新真实经历计数。索引是同步事务写入，无异步索引水位竞态；全文词片不构成一般语义理解。读取旧承诺原文时补上当前取消/改约版本，防止旧真话冒充现在安排。

## 弱点与停止条件
- 语言解释与表达未实测，是当前最关键未知；无来源造约定、误把条件句定案、口头承诺不落库都要算失败。
- 默认后验只有两类有限特征，不能代表对人情感的理解；少样本可能误判，应看源反馈并允许冻结/纠正。
- 简单计数在合成Brier比较更好，故默认使用；SGD权重更新本身无额外科学优势。
- I/O/重启可靠、绿色测试 ≠ 主观体验、EGO ready、长期用户收益。
- 任一取消后继续执行、旧日期恢复、删除内容重新出现或保存失败仍声称记住，阻止对应发布，先解决根因。
- 完全同信息的持久承诺表＋全文检索也能覆盖本轮大量功能。这是应复用的基础设施，不以击败它为主观性证明。

## 测量合同
测试/合成流必须与真实模型能力分开报告。100k压力流只有三条命名/中文原文查询，不能改称100k语义QA或长时程人格验证。记录输入复算不重新调用服务商、不证明对方模型身份和输出真实性。删除重基后的初始投影只验证结构，一般重算不认证其历史真实性。
