# SharedField v0.7 — 可检查的共同阅读与方法延续

> **当前方向已更新为桌宠共同生活。** 本页保留 v0.7 阅读实验的实际用法与限制，不是当前开发任务。请先看 [项目任务板](../TASK_BOARD.md) 和 [当前入口](PROJECT.md)。以下“本轮”“现在使用”及费用上限只适用于历史阅读版本；不要求先完成旧阅读实验再开发桌宠。

本轮把一次共同阅读接入已有长期记忆与聊天：原文 → 真实阅读 → 用户纠正 → 重读与方法建议 → 用户采纳 → 新材料同历史对照 → 评价与重启接续。工程链已实现；真实模型目前完成首次阅读和依据用户纠正重读，尚未完成方法采纳与真实迁移评价，不能宣布成长有效。

## 现在使用

本机双击 `START_READING_WINDOWS.bat`，或打开已运行的 [一起读](http://127.0.0.1:8777/reading)。个人经历在 `user_data/reading_v07_final/`，已包含经验证接入的原 v0.6 记录与本轮实际阅读。电脑重启后重新运行启动器；启动保持暂停，不补造经历或重发已完成请求。

启动器只从用户指定 `D:\Project\MyAIWorkspace\openrouter.txt` 中读取 `codex key` 标签对应的密钥，仅留在进程；不把密钥放入导出。固定模型 `openai/gpt-5.4`，本次验证跨重启累计最多16次、保守预留最多1美元。可传其他密钥文件路径：`START_READING_WINDOWS.bat "C:\path\keys.txt"`。没有新增 Python 依赖，需要 Python 3.10+。

普通入口 `START_WINDOWS.bat` / `python run.py memory` 仍可使用自己的模型配置，默认端口8774、数据目录 `user_data/memory/`，与上述个人验证数据不同。普通入口只有调用次数限制，不能当作美元封顶入口。

## 能做与还不能证明的事

- 文本来源、逐字引用、用户纠正、方法范围与例外均留下来源；同类后续阅读使用已采纳方法，最近活动可进入普通聊天。
- 新材料比较双方看到相同原始历史，仅一方额外获得方法；先评分后揭示。手动交换、模型配置不一致不能认证公平模型增益。
- 可暂停、撤回方法、删除来源及其依赖，备份与恢复保留活动进度。新代码与旧经历之间使用冻结验证器显式迁移，未修改用户原存档。
- 实际学习是有来源的外部方法记忆，未训练基础模型权重。它可能没用或学偏；一次好回答不证明主动履约、一般成长、人类动机或完整 Joi-like 体验。
