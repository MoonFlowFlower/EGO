模型连接与节奏

本地模式不是通用聊天模型。API 对话通常两次请求；可选的事件讲述一次请求。模型错误会停止，不自动收费重试。

个体重置与数据

新探索保留经历；新个体会把旧生命周期完整归档并开始空白状态。导出包含你的对话，不要公开分享未经检查的文件。

手动语言交换

复制请求给你选择的模型，再贴回完整 JSON。解释和表达分两阶段。你操作地图不会吞掉回答；旧快照会标注。暂停、新问题或改变共同约定会取消旧请求。

0. 可以点“接着旧探索”导入v0.4/v0.5导出；已有个体先归档。迁移后暂停，未完成请求不会自动重发。
1. 点“一起走”后让她探索 8 步，或点选邻接地点后亲自移动、调查。你们有各自的位置，分享同一环境的观察。
2. 直接问感觉、思考与意愿。未连接模型时是数值状态报告；连接模型后是受状态约束的自然语言。
3. 点“等我一下”测试真实等待，再点“我准备好了”。已授予的剩余步数保留，暂停后仍需重新授权。点回答下的快照，检查说法是否来自此前经历。展开状态面板，观察预测误差、能力估计、候选选择和来源。
4. 在实验对照中制造工具故障或路况变化，观察她是否调查、校准、维护或修订目标。目标是能发现失败，不是保证每次都聪明。
5. 可开始新探索保留跨场景统计，也可导出。关闭后恢复会暂停；密钥重启后重填。
