# EVOLAB-001A / E2 预注册

冻结日期：2026-10-02（文档阶段冻结）。以下假设、指标、阈值和判定规则，在任何 E2 正式运行开始前就已固定。E1 阶段允许调整的只有世界参数（见 `DESIGN.md`），而且必须在冻结 `configs/e2_frozen.yaml` 之前完成。本文件中的阈值任何时候都不改。

## 记号

- A = `gru_fixed`，B = `gru_mb_plastic`，B0 = `gru_mb_frozen`（B 的最终基因组在评估时取 η=0）。
- S(X, 条件) = 臂 X 的 5 个种子各自最终基因组在该保留集条件下的平均存活比例（每个种子 1024 个回合），再对 5 个种子取平均。
- drift 指标 = `drift_fast` 与 `drift_slow` 两个条件的等权平均。在 `drift` 世界中训练的运行用这个指标评估；在 `static` 世界中训练的运行用 `static_holdout` 评估。
- 置信区间：分层自助法（hierarchical bootstrap）。先有放回地抽 5 个种子，再在每个被抽中的种子内有放回地抽回合，重复 10000 次，取 2.5% 与 97.5% 分位数。
- δ = 0.10 × S(A, drift)，即 A 在漂移条件下平均存活的 10%（相对量）。

## 假设

**H1（主假设，漂移下可塑性有收益）**：在漂移世界训练、漂移保留集评估时，以下两条同时成立：
- S(B) − S(A) ≥ δ，且该差值的 95% CI 下界大于 0；
- 5 个种子按编号配对比较，至少 4 对满足 B > A。

**H2（收益来自可塑性本身）**：H1 成立时，[S(B) − S(B0)] ≥ 0.5 × [S(B) − S(A)]。也就是说，关掉可塑性会失去至少一半优势。

**H3（收益只在有漂移时出现）**：在静态世界训练、`static_holdout` 评估时，S(B) − S(A) < δ_static，其中 δ_static = 0.10 × S(A, static_holdout)。

## 判定

| 结果 | 结论（写入 `E2_REPORT.md` 的措辞） |
|---|---|
| H1 ∧ H2 ∧ H3 | 正结果：在 Room-v0 测试规模下，演化出的三因子可塑性在漂移环境中带来存活优势，且优势依赖可塑性本身、只在漂移时出现。允许作为桌宠小核心的候选学习规则进入下一张卡。 |
| H1 ∧ H2 ∧ ¬H3 | 部分结果：B 在静态世界中也有优势，说明收益可能来自结构或容量而不是可塑性的适应作用。降级为"结构效应"，不支持可塑性结论。 |
| H1 ∧ ¬H2 | 部分结果：B 更好，但关掉可塑性后优势基本保留。收益来自 B 的结构而非学习，不支持可塑性结论。 |
| ¬H1 | 负结果：在这个规模下，演化出的可塑性没有超过循环网络的上下文内适应（与 X1 一致）。按负结果入账，不重调、不追加救援实验。 |

## 工程有效性前置条件

以下条件不满足时，本次实验判定为**无效**（工程失败），不是科学负结果：
- 在训练所用世界上，A 和 B 的最终存活都显著高于随机基线 R（95% CI 不重叠）。
- 20 次运行全部完成，没有因 NaN 或崩溃丢失。如有丢失，只允许用相同种子重跑一次，并在 `PROGRESS.md` 记录。
- 重放测试通过（或逐位不一致已按 `DESIGN.md` 第 6 节记录说明）。

判定无效时，允许修复工程问题后重新冻结配置再跑。每次重跑都要在 `PROGRESS.md` 写明原因，并且必须在查看任何保留集结果之前做出重跑决定。

## 禁止事项

- 看到保留集结果后修改 δ、指标、条件定义、选择规则或种子数。
- 用中途的最佳检查点替代第 400 代均值基因组。
- 在开发期间使用保留集种子。
- 根据结果有选择地报告某个保留集子条件。两个漂移子条件都要报告，判定只用它们的等权平均。

## 报告必须包含

- 上述各项差值及其 CI；
- 每臂各一条代表性训练曲线；
- 实际消耗的 GPU 时间；
- 一个 B 臂个体在 drift 回合中的 GIF。可以的话，叠加显示调质信号 m_t 和"认为好"的颜色随时间的变化。
- 一段"本结果不能证明什么"。
