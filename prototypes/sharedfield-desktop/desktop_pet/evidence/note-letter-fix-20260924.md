# 便签编辑与回信修复 · 2026-09-24

用户反馈：旧信件是空泛流水账，页面不能写便签。定位到旧 `_finish(write)` 直接拼接固定开场、两条事件标题和固定结尾；旧按钮只读取现有文件，没有编辑入口。不是本次模型理解失败。

## 已实现

- 页面内新建、编辑、保存 UTF-8 txt/md 便签；6000字上限，版本冲突保留草稿，路径限制在小屋 workspace。
- “只保存”不调用模型。“保存并请她读”携带保存版本校验，完成阅读即持久化该版本回信任务；写信动作绑定任务，连续阅读不会覆盖前一张待回信内容。
- 回信使用完成阅读时的原文，记录来源并可在信下展开。同名同内容最多一个任务；中断或失败不自动重发，不用模板代替。
- 停止定时生成空泛模板信。旧信保留。自主生活的开放式分享尚未补齐，不能把本次便签回信修复当作最终共同生活方案。
