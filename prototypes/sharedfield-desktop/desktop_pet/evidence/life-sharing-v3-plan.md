# 2026-09-26：生活事实与原创想象分离

依据：用户已认可幻想、创作和真实发生分开。actor-v1/v2失败记录保留。本轮不再评估自由散文能否充当执行证明，不修改旧结果。

修改：生活信包含应用从真实完成记录构造的fact_text，与模型新创作的imagination两种字段。界面明确显示“脑海里的小剧场 · 虚构”，纯文本导出同样保留标记。模型不能写fact_text。再次聊天只取得fact_text、真实来源及“写过一个虚构片段”的存在记录，虚构内容不进入事实上下文。便签回信保持原路径。旧生活散文任务不自动升级或重放。

权衡：这是可检查的“完成一件事→创作联想→留信”体验，不等同自由、自然的个人反思。事实部分用短小固定表达会比较朴素，避免重新堆砌流水账；自动分享仍最多首次吃饭、首次休息各一次。
