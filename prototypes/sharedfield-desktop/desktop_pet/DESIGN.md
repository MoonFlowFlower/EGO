# 桌宠体验框架 · 2026-09-23

用户最新决定：先交付能亲自体验的框架，暂停让记忆评测阻塞产品。沿用已确认的小房间、Live2D、性格、聊天、信件、教学、自主生活与保存恢复目标。

本次实现：独立desktop_pet目录；Python标准库本地服务与SQLite持久层；本地网页可直接打开，并提供桌面独立窗口启动器。角色图集以CSS裁片使用；本地导入用户的Live2D，不向模型传送贴图、不再分发。俯视房间与面对面交流切换。复用已有OpenRouter凭据读取方式及已核验模型配置，不重开实验活动。

生活循环：页面连接 → 根据需要、已教自理、忙碌约定选择活动 → 走到物品附近 → 完成后提交状态与经历 → 回到自主选择。关闭页面停止推进，重开不补造离线经历。教学和分享偏好作为明确持久规则，普通对话与活动经历保留原始记录；这是可替换的简单记忆框架，不宣称ACE或人格训练通过。

最短体验：选性格 → 点小人交流 → 教自理 → 告知忙5分钟 → 看她安排生活并留信 → 回来读信 → 关闭重开观察存档。

范围：原SharedField、个人存档、memory_lab不修改。不读屏、不观察软件、不操作整机。允许读取的内容仅本体验版workspace内文本，界面明确通过“共读便签”读取真实文件。基本生活不调用模型；聊天才按需调用并记录失败与费用。后台不做无界模型实验。

验证：真实SQLite动作完成、教学生效、忙碌留信、重开不推进、重复命令去重、文件边界与HTTP同源；浏览器检查房间、操作、Live2D实际渲染和真实模型聊天。未完成之处明确标注。
