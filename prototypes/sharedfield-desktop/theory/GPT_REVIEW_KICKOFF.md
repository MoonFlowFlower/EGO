你好。请你担任**独立的对抗性审核者，同时也是合作研究者**，审核附件中的理论文档《图式复利：低算力、可持续成长智能的理论假说》（v0.1）。这份文档由 Claude（Anthropic）与项目负责人讨论后写成。请不要因为作者是谁而偏袒或贬低，只看证据和推理。我们要的不是好评，而是：这条路能不能走通；如果走不通，有没有更好的路。

**背景**
- 我们在做一个"活的"电子生命桌宠：有自己的需求，持续运行，会从经历中慢慢成长。大模型负责语言，一个小核心负责需求和在线学习。
- 硬约束：在线学习必须在一块 RTX 5070 Ti Laptop GPU（12 GB，会热降频）上本地完成。不追求能力特别强，追求"会自己学、慢慢变强"。
- 不宣称意识、情感、能动性或自主性。研究纪律：预注册后不改阈值，负结果如实记录，不做救援实验。
- 文档第 1.3 节和附录 A 是我们自己的实验数据（EVOLAB-001A / 002A）。如果你能访问 GitHub 仓库 `MoonFlowFlower/EGO`（分支 `codex/desktop-pet-memory-lab-20261001`，目录 `prototypes/sharedfield-desktop/evolab/evidence/`），请直接核对原始 JSON；不能访问的话，以文档里的数字为准，并注明"未核对原始数据"。

**你的任务**
1. **核对证据**：逐条核对文档引用的研究和数字，优先核对标【未核对】的条目。每条给出三种结论之一：正确；有误（并写出正确内容）；无法核对（说明原因）。不要凭记忆编造引用，查不到就说查不到。
2. **审核推理**：第 3.3 节的代价分解和第 3.4 节的复利命题是否成立？有没有隐藏假设、循环论证或跳步？如果能给出更严格的形式化（或证明它不成立），请写出来。
3. **审核新颖性**：第 9 节声称的四个新点，哪些其实已有人提出过？请给出处。
4. **审核预测与实验**：八条预测是否真正可证伪、能区分竞争理论？四个实验有没有混杂因素、不公平的对照，或者在笔记本预算内跑不完的问题？请直接给出修改后的设计。
5. **提出更好的方案**：如果你认为有更好的统一原理或架构，请用同样的严格度写出来，包括机制、证据、可证伪预测、判决实验、算力估计。这也包括你自己的方法，比如你在 ARC-AGI-3 上即时构建符号世界模型的方式：它能否在我们的笔记本约束下以某种形式实现？请先把竞争方案的最强版本讲清楚，再做比较，不要只挑这份文档的毛病。
6. **指出风险**：最可能让这条路线失败的三个问题，以及陪伴型智能体特有的伦理风险。

**输出格式（请用中文）**
1. 一句话总评：接受为工作假设 / 需要修订 / 应当放弃，并给出信心（0–100%）。
2. 证据核对表：条目 | 文档说法 | 核对结果 | 来源链接 | 是否打开过原文。
3. 推理问题清单，按严重 / 一般 / 轻微分级。
4. 新颖性评估。
5. 预测与实验的修改建议（直接给出修改后的版本）。
6. 竞争方案或更优方案（如果有），按"能否在笔记本上更快、更便宜地被判决"排序。
7. 你推荐的唯一一个下一步实验，以及理由。
8. 你自己不确定的地方，逐条标出。

**规则**
- 每个事实性论断都给出来源链接，并区分"打开原文核对过"和"凭记忆"。
- 推测要明确标为推测。
- 宁可说"我不知道"，也不要编造。
- 不要只说好话；如果整个理论站不住，就直接说。
