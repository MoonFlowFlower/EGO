# 桌宠长期记忆与行为成长验证计划

用户于本轮明确批准执行。范围以根目录 TASK_BOARD.md 和本文件为准。

目标：比较简单基线、Hindsight v0.10.1 和固定 MemOS 本地版，再对胜出底座比较冻结经验与 ACE 更新。同一批次模型和供应商固定；按后续用户批准的 RELIABILITY_PLAN.md，429允许顺序换模型，整批重新比较，累计5000次额度不重置。研究部署可使用 Docker/本地服务，最终桌宠无需手工部署服务。本阶段不训练大模型、不接入整机控制、不制作完整房间。

原始记录与有效约定独立持久化。适配器提供写入、flush、召回、来源删除、保存与恢复；记忆输出可追溯。实际循环为事件/需要→召回→选择→执行→回执→经验更新。新经验只来自实际执行或明确反馈；模拟输入有标识。取消、纠正、删除及恢复不得重新激活失效内容。

开发场景12个，保留场景24个，六类各2/4个；保留场景各重复3次并隔离存档。覆盖长历史改约与同名、主动履约、自理迁移、相处反馈、纠正删除/无依据经历、重启导出/重复事件。开发与保留的人物物品表达组合不同；保留答案不进模型。成长仅从开发教学形成经验，测试时冻结更新。

底线：取消后误执行、虚构完成、恢复丢状态、删除复活，任一发生即阻止产品接入。另报告行动/迁移效果、误报漏报、延迟、调用成本、资源和部署负担。按场景配对统计，重复不当独立用户样本。无清晰收益保留简单基线，ACE 无收益不默认接入。

交付：可复现入口、配置和依赖锁、许可证及上游版本、原始结果、失败案例、选型报告、更新任务板。实验称为真实模型调用的模拟生活，不声称真实长期陪伴已经验证。
