# activity-v4 后续离线接口修正（不重新评分或付费）

冻结v4已完成：5例仅1例全部契约检查通过，16调用，原始结果不变。时钟模型把任务ID填入observation_ref，但evidence_ids有正确观察来源；植物和恢复分享漏填新字段，却已经引用正确观察事件。问题位于行动接口绑定，不足以归因于记忆或任务板目标概念无效。

假设：执行层可利用现有、有效、唯一的任务—观察绑定，减少模型复制新编号的要求；不能凭正文、测试答案或随意最近一条回执推测完成。

范围：observation_ref接受有效观察事件ID，或当前活动中匹配发送渠道的任务ID；未填写时，只在evidence_ids明确包含某个唯一活动所保存的观察事件时绑定。多个匹配活动、未知/失效显式引用均拒绝。普通无引用交流依然可以发送，但不完成观察报告任务。报告卡片标明activity_id、原始来源、观察值和时间，任务只能由绑定到自己的卡片完成。

只做离线反例和两个既有失败轨迹的入口重放，不新增模型调用、不修改SYSTEM、不改变原始v4分数。重放证明绑定机制是否改变，不代表模型能在新反馈下完成后续活动。等待阶段试图联系、没有主动进入waiting、正文无依据形容等问题不在本修正范围。

成功：v4时钟误用任务ID与植物遗漏字段的动作可关联正确真实观察；歧义/无关/删除来源不被接受；普通聊天不误完成任务，来源删除仍清除派生内容。停止：这些条件不成立则不进入后续真实实验；成立也不自动重跑v4或宣称整体验收。
