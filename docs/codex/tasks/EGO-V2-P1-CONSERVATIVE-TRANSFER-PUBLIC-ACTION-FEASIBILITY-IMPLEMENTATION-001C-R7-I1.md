## Problem definition

Implement a standard-library-only, outcome-neutral verifier for the exact R7
theorem contract. It must derive the ten loss-geometry quotient classes, six
compatible completions, all 63 nonempty member masks, the public L1
median/minimax action, exact loss-sum receipts, and the strict/bounded
constraint contradictions using unbounded Python integers.

The producer is a verifier only. It does not implement source reuse, Bayes
weights, neural learning, acquisition, navigation, a controller, or a product
action.

## Hypothesis and falsifier

- **H1-strict:** some public alias class has an action giving every exact-member
  completion at least `437,500` total-error-micro benefit while every nonmember
  completion has regret at most zero relative to the public L1 median.
- **H1-bounded:** some public alias class meets the same member benefit while
  every nonmember regret is at most `87,500`.
- **Falsifier:** the complete exact loss-sum proof yields zero feasible masks
  for both contracts.

The executable/banked verdict is unknown until callable computation and
fresh-process replay finish; the parent analytic argument predicts the negative
branch but is not yet generated evidence. Expected values may appear only in
tests after outcome-neutral dispatcher branches and the exact
`true_gain=0,A=B` positive control are proven.

## Baselines

- **Primary:** `PUBLIC_PREFIX_L1_MEDIAN_MINIMAX`, derived from each three-vector
  remaining set.
- **Historical diagnostic only:** R5 scratch posterior mean, recomputed with
  exact half-even integer division. It cannot serve as the R7 admission
  baseline.
- **Unrestricted challenger:** any mask-dependent, target-truth-blind public
  action. The theorem quantifies over this superset, so no concrete optimizer is
  needed when the action intersection is proven empty.

## Ablations and positive controls

1. Recompute the R5 mean and report geometries where it has larger six-truth
   aggregate loss than the L1 median.
2. Using the same loss path, set the synthetic true-gain threshold to zero and
   action `A=B`; verify zero gain/regret on all six completions and reach the
   strict-feasible dispatcher branch.
3. Feed synthetic summaries to prove dispatcher priority for private input,
   instrument-invalid, two-sided-absent, bounded-only, and strict-feasible
   outcomes.

No unfrozen threshold-lowering or always-transfer mutation is permitted.

The tests must establish that, for every public bank `B` and legal history `H2`,

all six possible realized truths. The ten remaining sets are complete only as a

mask and every action.

Tests must permute observed-token order, unobserved-token labels, and prototype
labels and verify that loss/mask relabelling preserves the receipt and verdict.
No source bank is required as a producer input because arbitrary bank-dependent
actions are included in the universal action quantifier, not because bank data
is ignored.
