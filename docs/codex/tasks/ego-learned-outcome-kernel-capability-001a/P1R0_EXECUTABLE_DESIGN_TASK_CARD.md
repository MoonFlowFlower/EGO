## 2. Problem definition and real objective

The real objective is not to make the prior 30 temporary tests green again.

The objective is to determine whether the frozen P0 contract can be mapped, without changing its surface, thresholds, roles, splits or seeds, into one implementable and auditable code design that prevents the exact prior failure classes:

- baseline stubs, aliases, wrong targets or degenerate placeholders;
- fake SMC without sequential update, ESS and systematic resampling;

## 3. Bounded audit

### Hypothesis

A machine-checkable design crosswalk can map every frozen requirement to:

- one owned module;
- one callable symbol or state-machine transition;
- one legal input boundary;
- one failure mapping;
- one focused test;
- one negative control where applicable;
- one provenance record;
- one future formal artifact field.

If this cannot be done without changing P0, the replacement implementation must not be authorized.

### Strongest baseline explanation

The cheapest explanation for a future green P1R1 result is still that one generic predictor, empty lookup, wrong label, static verdict or test-only path was exposed behind many required IDs.

The design must make that shortcut structurally visible before code exists.

### Strongest reason this task may be invalid

The frozen surface may be overconstrained or internally ambiguous, especially across:

- P1-only DEV seed domains versus P2-only formal/reference seed domains;
- 20 invalidating controls with distinct role semantics;
- SMC randomness and deterministic replay;
- expected-risk metrics using legal q rather than realized labels;
- formal success-path existence without P1 formal execution.

If any ambiguity requires changing the frozen contract, return BLOCKED. Do not repair P0.

### Falsifiers

This design framing is falsified if:

- any mandatory baseline cannot receive a unique callable and fit/update design;
- SMC cannot be specified without private state, hidden labels or post-P1 tuning;
- formal authorization cannot dominate seed derivation and output creation;
- the same producer cannot serve DEV and future formal modes without a second logic path;
- metric, intervention or replay requirements cannot be mapped to independent tests;
- required ignored residue cannot be isolated;
- any frozen object or governance authorization must change.

### Evidence still insufficient

Even a complete blueprint and passing structural lint do not prove:

- a conformant instrument can actually be implemented;
- DEV controls pass;
- formal execution is safe;
- the synthetic surface has fair headroom;
- any candidate can learn;
- any product or mechanism is valid.

### Mechanism classification

This task tests design completeness and evidence hygiene only. It does not test a mechanism or behavioral resemblance.

### Ablation requirement

P1R0 runs no ablation. The blueprint must map all six frozen information interventions to future real reruns, held-fixed inputs, expected failure directions, test IDs and provenance fields. A report-only or stored-score edit is not an ablation.

### Trace/replay requirement
