Deliver a default-off, explicit-launch survival-learning mode inside the sole
Ego V2 reducer. Fixed energy/safety homeostatic deficits are the drive. A
legal-public learner must acquire anonymous action-conditioned consequences
from observations and actual feedback. A planner must combine deficit,
predicted consequences, terminal risk, and uncertainty. The existing
controller, SQLite append/recovery, replay reducer, terminal lifecycle, and
visual console remain the only behavior and presentation path.

The initial product lane uses the bounded public Bayesian reference established
by 001K. It is not a neural-success claim. A minimal two-timescale learner is
authorized only if the separate 001L robustness successor passes its unchanged
qualification and replication gates.

## Public input and state contract

The learner may receive only current public policy observation, energy/safety,
the prior action, the actual public outcome/delta, its own JSON state, and its
declared RNG. It must not receive world/seed/layout/mapping identity, private
pose or object coordinates, cause labels, oracle action, split/packet/verdict,
or future information.

State exposes `plan_action`, `update_after_transition`, `reset_for_respawn`,
and `reset_for_world`. Long-term consequence statistics survive respawn;
short-lived navigation/credit state resets. World reset clears world-local fast
state without silently deleting allowed long-term structure.

## Runtime and observability acceptance

1. A mutually exclusive `homeostatic_transfer_mode` is default `off`; when on,
   SARSA and factored MPC neither learn nor decide.
2. The final action selected by the existing downstream selector equals the
   homeostatic plan; posterior updates occur only after actual transition and
   metabolism.
3. Trace/UI/terminal report energy, safety, deficits, predictions per action,
   actual outcome/delta, posterior/slow/fast hashes, update count, uncertainty,
   terminal risk, selected action, and selection reason.
4. SQLite recovery recomputes through the same `compute_step`; stored action or
   prediction is never used as replay behavior input.
5. Death preserves declared long-term knowledge and clears only fast state.
6. Same observation and predictions plus a drive intervention changes ranking
   toward the dominant deficit; disabling the drive removes this sensitivity
   without changing predictions.
7. Provide a direct launch command and a trace-derived HTML report.

## Controls and claim ceiling

Evaluation includes scratch, no-update, feedback shuffle, posterior ablation,
slow reset, fast reset, and random. Transfer claims require earlier adaptation
than scratch and recovery from a wrong prior. Row recomputation, replay,
leakage, trace/state/assignment tamper controls fail closed.

At most this task may establish a runnable benchmark-local homeostatic control
loop that learns public action consequences and uses them in a fixed planner.
It cannot establish consciousness, subjectivity, agency, free will, a
self-generated goal, general transfer, real-world survival, or electronic life.
