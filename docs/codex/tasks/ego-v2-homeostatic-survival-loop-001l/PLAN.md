## Decisions

- New mode is orthogonal in state but mutually exclusive in command validation
  with SARSA and factored MPC.
- Predictions are goal-independent; fixed homeostatic drive is applied only in
  planner ranking. This makes drive interventions diagnostic.
- Long state is token/action consequence evidence; fast state is navigation
  target and short interaction history. Respawn preserves long state and clears
  fast state.
- No ordinary tuning choice requires operator input; hard boundaries do.

## Rollback

The mode is default-off. Reverting the task commits restores byte-identical
predecessor behavior; no schema migration or remote publication is performed.
