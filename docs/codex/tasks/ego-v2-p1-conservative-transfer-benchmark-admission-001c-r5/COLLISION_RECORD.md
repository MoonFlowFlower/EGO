## Why the selected route is narrower and stronger

The selected route first asks a feasibility question already addressed by
standard finite Bayesian model comparison and experimental design.  Its exact
120-permutation reference has no fitted noise, no target-tuned prior, no neural
approximation, and no hidden cause name.  It separates:

1. fixed-packet inference;
2. acquisition policy;
3. common public-only navigation;
4. private post-checkpoint scoring.

The preregistered `3 x 3` inference/acquisition cross-feed panel distinguishes
transfer inference from active acquisition.  Source deletion, sham source,
matched scratch+local, passive acquisition, and consistency elimination attack
the cheapest alternative explanations before any product-path candidate.
