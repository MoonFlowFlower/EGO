## Ablation requirement

The live path must expose and tests must intervene on:

1. Memory OFF: no memory reads/writes and every memory-bias term is zero.
2. Learning OFF: outcome-model count/EMA bytes remain unchanged.
3. Consolidation Replay OFF: no consolidation batch or new consolidated entry.
4. Stored selected-action deletion/tamper: recovery still recomputes or fails
   closed; it never accepts the stored action as an input.

These are product engineering interventions, not formal causal attribution.

## Trace/replay requirement

One pure `compute_step` path must serve live operation and recovery. Each trace
records producer, command, toggles, state hashes, context, goals, candidates,
prediction/model ref, memory refs, selected action, actual delta, prediction
error, update, consolidation refs, code-path hash, and event-chain hashes.
Restart recovery reads only serialized initial metadata plus commands, reruns
`compute_step`, and compares recomputed traces/state hashes. A mismatch fails
closed.
